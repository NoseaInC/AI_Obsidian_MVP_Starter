# Assistant Chat-first Specification

## Scope

This iteration changes only the Assistant experience and its links to Today, Materials, Review and Plan. The existing Runtime, provider security, Prepared workflow and reviewed/core protections remain authoritative.

The Assistant is the single free-form entry. Each submitted goal creates one Task Thread and one Artifact Group. Structured modules display the durable consequences:

- Today receives explicitly added learning work.
- Materials receives imported or research material state.
- Review receives Change Sets and reviewable drafts.
- Plan receives proposed or confirmed study tasks.
- Assistant retains the conversational task history and editable result versions.

## Acceptance contract

- Three-column desktop composition: module navigation, chat/task/result, task context.
- Header order: selected model, history, new conversation, provider settings.
- Exactly five human-facing task steps.
- One primary result card per Task Thread; quizzes stay inside a Learning Pack.
- Explicit retry and recovery choices for partial or failed tasks.
- All writes remain Change Set gated; reviewed/core notes remain immutable.
- Narrow layouts collapse the context rail without breaking the conversation or composer.
