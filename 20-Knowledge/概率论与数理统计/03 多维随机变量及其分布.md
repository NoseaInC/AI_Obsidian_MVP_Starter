# 03 多维随机变量及其分布（教材版）

> 学完本章你将能：理解联合、边缘、条件分布三者之间的关系（积分/求和 vs 除法）；用「乘积可分解」判断独立性；计算两个随机变量之和的分布（卷积）；区分相关与独立并理解协方差矩阵；熟练使用条件期望与迭代期望公式解决分层问题。

## 学习目标

1. 写出联合分布/密度，并能求边缘与条件分布；
2. 用分布可分解性判断独立性，理解「独立 ⇔ 任意函数独立」；
3. 求 $Z = X+Y$ 的分布（卷积），理解正态可加性；
4. 掌握协方差、相关系数、协方差矩阵及其性质；
5. 深刻理解「不相关 ≠ 独立」，能举反例；
6. 会用迭代期望公式 $\mathbb{E}[Y] = \mathbb{E}[\mathbb{E}[Y\mid X]]$ 和全方差公式；
7. 能把多维分布工具用到数据科学（相关性分析、共线性、PCA）。

## 3.0 引言：为什么要研究多维？

现实几乎都是多维的：

- 用户：年龄、收入、消费、活跃度同时被观测
- 风控：多个特征一起预测违约
- A/B 测试：同一批用户的多个指标

单变量分布回答「一个变量如何分布」；**多维分布回答「多个变量如何一起分布、彼此有什么关系」**——这正是相关性、回归、PCA 的数学基础。

## 3.1 联合、边缘与条件分布

### 联合分布：同时描述 X 和 Y

- 离散：联合分布律 $p_{ij} = P(X=x_i, Y=y_j)$，满足 $\sum_i\sum_j p_{ij} = 1$
- 连续：联合密度 $f(x,y) \ge 0$，$\iint_{\mathbb{R}^2} f(x,y)\,dx\,dy = 1$，$P((X,Y) \in D) = \iint_D f(x,y)\,dx\,dy$

### 边缘分布：只关心其中一个

把另一个「积掉/加掉」：

- 离散：$p_{i\cdot} = P(X=x_i) = \sum_j p_{ij}$（把 j 全加起来）
- 连续：$f_X(x) = \int_{-\infty}^{\infty} f(x,y)\,dy$

**直觉**：联合是「整张表」，边缘是「行的合计」（对 X）或「列的合计」（对 Y）。

### 条件分布：给定一个后另一个的分布

- 离散：$P(Y=y_j \mid X=x_i) = \dfrac{p_{ij}}{p_{i\cdot}}$
- 连续：$f_{Y\mid X}(y \mid x) = \dfrac{f(x,y)}{f_X(x)}$（分母不为 0 时）

**例（掷两颗骰子）**：X=第一颗，Y=两颗之和。
- 联合：36 个等概率组合
- 边缘：$P(X=3) = 6/36 = 1/6$（第一颗为 3 的 6 种组合）
- 条件：给定 $X=1$，Y 均匀取 {2,…,7}，每个概率 1/6

## 3.2 随机变量的独立性

**定义**：X 与 Y 独立 ⇔ 对任意取值组合

$$P(X=x, Y=y) = P(X=x)\,P(Y=y) \quad(\text{离散}); \qquad f(x,y) = f_X(x)\,f_Y(y) \quad(\text{连续})$$

**直觉**：知道 X 不会改变 Y 的分布——联合可分解为边缘之积。

**重要推广（面试常考）**：X 与 Y 独立 ⇒ 对任意（可测）函数 g, h，$g(X)$ 与 $h(Y)$ 独立。例如 X,Y 独立 ⇒ $X^2$ 与 $e^Y$ 独立。

**例**：X=第一颗骰子，Y=第二颗骰子——独立。但 X 与「两颗之和」不独立（知道 X=6 则和至少为 7）。

## 3.3 多维随机变量函数的分布

### $Z = X+Y$ 的分布（卷积）

- 离散：$P(Z=z) = \sum_x P(X=x,\ Y=z-x)$（独立时 $= \sum_x p_X(x)\,p_Y(z-x)$）
- 连续（独立时）：$f_Z(z) = \int f_X(x)\,f_Y(z-x)\,dx$（**卷积公式**）

**例（两个均匀之和）**：$X,Y \sim U(0,1)$ 独立，$Z=X+Y$ 的密度是三角形：

$$f_Z(z) = z\ (0\le z \le 1), \qquad 2-z\ (1 \le z \le 2)$$

直觉：和接近 1 的组合远比接近 0 或 2 的多——所以两个均匀加起来不是均匀。

**正态可加性（重要结论）**：$X \sim N(\mu_1,\sigma_1^2)$、$Y \sim N(\mu_2,\sigma_2^2)$ 独立 ⇒ $X+Y \sim N(\mu_1+\mu_2,\ \sigma_1^2+\sigma_2^2)$。这是「误差叠加」和后续抽样分布的基础。

**💼 工作实战——总销售额的分布**：每日订单数 N（泊松），每单金额 M（某分布），日总销售额 $S = M_1+\cdots+M_N$。E[S] 用条件期望（3.5 节），分布用「复合分布」模拟：

```python
import numpy as np
n_days = 100000
sales = []
for _ in range(n_days):
    n = np.random.poisson(50)          # 每天 50 单左右
    amt = np.random.exponential(80, n) # 每单约 80 元
    sales.append(amt.sum())
sales = np.array(sales)
print(f"日均销售额 ≈ {sales.mean():.0f}，95% 区间 ≈ {np.percentile(sales,[2.5,97.5]).round(0)}")
```

## 3.4 协方差与相关系数

### 协方差

$$\mathrm{Cov}(X,Y) = \mathbb{E}[(X-\mathbb{E}[X])(Y-\mathbb{E}[Y])] = \mathbb{E}[XY] - \mathbb{E}[X]\,\mathbb{E}[Y]$$

- 正：X 大时 Y 倾向大；负：X 大时 Y 倾向小；0：无线性趋势
- 性质：$\mathrm{Cov}(X,X)=\mathrm{Var}(X)$；$\mathrm{Var}(X\pm Y) = \mathrm{Var}(X)+\mathrm{Var}(Y) \pm 2\mathrm{Cov}(X,Y)$；$\mathrm{Cov}(aX, bY)=ab\,\mathrm{Cov}(X,Y)$

### 相关系数（标准化）

$$\rho = \frac{\mathrm{Cov}(X,Y)}{\sqrt{\mathrm{Var}(X)\,\mathrm{Var}(Y)}} \in [-1, 1]$$

$\rho$ 是无量纲的（协方差除以各自标准差），因此可以跨数据集比较相关强度。

### 协方差矩阵（多维推广，PCA 的核心）

对随机向量 $\mathbf{X} = (X_1,\dots,X_p)^T$：

$$\Sigma = \begin{pmatrix} \mathrm{Var}(X_1) & \mathrm{Cov}(X_1,X_2) & \cdots \\ \mathrm{Cov}(X_2,X_1) & \mathrm{Var}(X_2) & \cdots \\ \vdots & \vdots & \ddots \end{pmatrix}$$

- 对角元 = 各变量方差，非对角元 = 两两协方差
- **半正定**：对任意向量 $a$，$a^T\Sigma a = \mathrm{Var}(a^T\mathbf{X}) \ge 0$

**🎯 面试考点——「协方差矩阵为什么半正定？PCA 怎么用它？」**：$a^T\Sigma a$ 是线性组合 $a^T\mathbf{X}$ 的方差，必然非负，所以半正定。PCA 就是求 $\Sigma$ 的特征分解，最大特征值对应方向是「方差最大的投影」——降维的本质是找数据变化最大的方向。

### 「不相关 ≠ 独立」（必考反例）

**反例**：$X \sim U(-1,1)$，$Y = X^2$。

$$\mathrm{Cov}(X,Y) = \mathbb{E}[X^3] - \mathbb{E}[X]\,\mathbb{E}[X^2] = 0 - 0 = 0$$

但 Y 完全由 X 决定，显然不独立。

**结论**：
- 独立 ⇒ 不相关（成立）
- 不相关 ⇏ 独立（不成立，除非联合正态）
- **正态例外**：联合正态下，不相关 ⇔ 独立

> 直觉：相关系数只捕捉**线性**关系；独立要求**所有**关系（包括非线性）都不存在。

## 3.5 条件期望与迭代期望

### 条件期望

$\mathbb{E}[Y \mid X=x]$：给定 X 后 Y 的平均水平，是 x 的函数（记为 $m(x)$）。

离散：$\mathbb{E}[Y\mid X=x] = \sum_y y\, P(Y=y \mid X=x)$；连续：$\int y\, f_{Y\mid X}(y\mid x)\,dy$。

### 迭代期望法则（全期望公式）

$$\mathbb{E}[Y] = \mathbb{E}\big[\mathbb{E}[Y \mid X]\big]$$

直觉：先按 X 分层求每层平均，再对各层平均加权平均（权重 = 各层概率）。

**例（分层）**：3 个班人数 20、30、50，平均身高 165、170、172。

$$\mathbb{E}[Y] = \frac{20\times165 + 30\times170 + 50\times172}{100} = 169.6$$

### 全方差公式（方差分解）

$$\mathrm{Var}(Y) = \mathbb{E}\big[\mathrm{Var}(Y\mid X)\big] + \mathrm{Var}\big(\mathbb{E}[Y\mid X]\big)$$

「总方差 = 组内方差的平均 + 组间均值的方差」——这是 ANOVA（第 8 章）和随机森林「OOB 方差分解」的思想源头。

**🎯 面试考点——「随机个数的和」**：$X$ = 进店人数，每人均消 30 元。$\mathbb{E}[\text{销售额}] = \mathbb{E}[\mathbb{E}[\text{销售额}\mid X]] = \mathbb{E}[30X] = 30\,\mathbb{E}[X]$。若 X 服从 Poisson(20)，销售额期望 = 600 元。方差用全方差公式：$\mathrm{Var}(S) = \mathbb{E}[\mathrm{Var}(S\mid X)] + \mathrm{Var}(\mathbb{E}[S\mid X]) = \mathbb{E}[30^2 X] + \mathrm{Var}(30X) = 900\times20 + 900\times20 = 36000$，标准差约 190 元。

## 💼 工作实战：多变量分析三板斧

### 1. 相关矩阵与热力图

```python
import pandas as pd
import seaborn as sns
corr = df[['age','income','spend','active_days']].corr()
sns.heatmap(corr, annot=True, cmap='RdBu')
```

高相关（|ρ|>0.8）特征提示**共线性**：放进线性模型会让系数不稳定、标准误膨胀——建模前先看相关矩阵是这个原因。

### 2. 条件期望与回归

线性回归 $\mathbb{E}[Y\mid X] = \beta_0 + \beta_1 X$ 本质上就是在估计条件期望函数。残差 = $Y - \mathbb{E}[Y\mid X]$，残差图无结构说明模型抓住了条件期望。

### 3. PCA 降维

协方差矩阵特征分解 → 主成分 = 方差最大的方向 → 用前 k 个主成分替代 p 个原始特征。

## 🎯 面试高频考点速览

1. **边缘分布怎么求？** 把另一个变量求和/积分掉。
2. **怎么判断独立？** 联合 = 边缘之积（对所有取值）。
3. **不相关和独立什么关系？** 独立 ⇒ 不相关；反向不成立（$Y=X^2$ 反例）；联合正态时等价。
4. **两个独立正态之和？** 仍是正态，方差相加。
5. **协方差矩阵为什么半正定？** $a^T\Sigma a$ = 线性组合的方差 ≥ 0。
6. **迭代期望 / 全方差公式？** $\mathbb{E}[Y]=\mathbb{E}[\mathbb{E}[Y\mid X]]$；$\mathrm{Var}(Y)=\mathbb{E}[\mathrm{Var}(Y\mid X)]+\mathrm{Var}(\mathbb{E}[Y\mid X])$。

## 练习（含解答）

**练 1**：联合分布律 $P(X=x, Y=y) = \frac{x+y}{30}$，$x=1,2$，$y=1,2,3$。求边缘与 $P(Y\ge2\mid X=1)$。

解：边缘 $P(X=1)=\frac{(1+1)+(1+2)+(1+3)}{30}=\frac{9}{30}=0.3$；$P(X=2)=0.7$。$P(Y\ge2\mid X=1)=\frac{3+4}{9}=\frac{7}{9}\approx0.778$。

**练 2**：$X,Y$ 独立，$X\sim B(3,0.5)$，$Y\sim B(2,0.5)$，求 $P(X+Y=2)$。

解：独立二项可加：$X+Y\sim B(5,0.5)$，$P=\binom{5}{2}(0.5)^5=10/32\approx0.3125$。

**练 3**：$X,Y$ 独立 $N(0,1)$，求 $\mathrm{Cov}(X+Y,\ X-Y)$。

解：$\mathrm{Cov}(X+Y,X-Y)=\mathrm{Cov}(X,X)-\mathrm{Cov}(X,Y)+\mathrm{Cov}(Y,X)-\mathrm{Cov}(Y,Y)=1-0+0-1=0$。

**练 4（经典反例）**：$X\sim U(-1,1)$，$Y=X^2$。计算 $\rho(X,Y)$ 并说明。

解：$\mathbb{E}[X]=0$，$\mathbb{E}[XY]=\mathbb{E}[X^3]=0$，故 $\mathrm{Cov}=0$，$\rho=0$。但 Y 由 X 决定，不独立——零相关只说明无线性关系。

**练 5（随机个数的和）**：每天订单数 $N\sim\mathrm{Poisson}(50)$，每单金额均值 80、方差 20²。求日销售额的期望与方差。

解：$\mathbb{E}[S]=\mathbb{E}[N]\cdot80=4000$。$\mathrm{Var}(S)=\mathbb{E}[N]\mathrm{Var}(M)+\mathrm{Var}(N)(\mathbb{E}[M])^2 = 50\times400 + 50\times6400 = 340000$，标准差约 583 元。
