# 05 统计量及其抽样分布（教材版）

> 学完本章你将能：理解「统计量是随机变量，其分布叫抽样分布」这一关键转折；掌握样本均值、样本方差的性质（含除以 n−1 的直觉）；理解 χ²、t、F 三大分布的构造、性质与用途；理解「正态总体下 $\bar{X}$ 与 $S^2$ 独立」这一看似反直觉的结论为何是 t 检验的前提；理解 Bootstrap 与解析抽样分布的关系。

## 学习目标

1. 区分总体、样本、统计量三个概念；
2. 掌握 $\bar{X}$ 与 $S^2$ 的期望、方差、分布；
3. 从标准正态「造出」三大抽样分布并记住关键性质；
4. 掌握正态总体的三大结论（X̄ 正态、卡方、独立）；
5. 理解 t 分布肥尾的直觉与小样本用 t 的原因；
6. 了解 Bootstrap 作为「经验版抽样分布」的原理。

---

## 5.0 引言：从「概率」到「统计」的转折

前 4 章是概率论：**已知分布，求事件概率**（正向）。

从本章起是数理统计：**已知样本，推断分布**（反向）。

问题：我们手里只有一份样本（比如 100 个用户的身高），但想知道总体的均值——样本均值 $\bar{X}$ 本身是随机的（换一份样本，$\bar{X}$ 就不同）。**$\bar{X}$ 的分布是什么？** 这个问题把概率论和统计连接起来：$\bar{X}$ 是一个随机变量，它的分布叫「抽样分布」。

---

## 5.1 总体、样本与统计量

| 概念 | 定义 | 例子 |
|---|---|---|
| 总体 | 全部个体的集合 | 全国 18 岁男生身高 |
| 样本 | 从中随机抽取的 n 个个体 | 随机抽 500 人 |
| 统计量 | 样本的函数，不含未知参数 | $\bar{X}$、$S^2$、中位数 |

**样本 $X_1,\dots,X_n$ 是 i.i.d. 的**：独立（互不影响）、同分布（都是总体的分布）。

**统计量是随机变量**：每次抽样得到不同值，它的分布就是**抽样分布**。

**🎯 面试考点——「为什么说统计量是随机变量？」**：统计量是样本的函数，样本是随机的，所以统计量也是随机的。你算出来的一个具体数值只是它的一个实现（realization）。

---

## 5.2 样本均值与样本方差

### 定义

$$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i, \qquad S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$$

### 三大性质（$X_i$ i.i.d.，$\mathbb{E}[X_i]=\mu$，$\mathrm{Var}(X_i)=\sigma^2$）

1. **无偏性**：$\mathbb{E}[\bar{X}] = \mu$
2. **方差收缩**：$\mathrm{Var}(\bar{X}) = \sigma^2/n$（n 越大均值越稳）
3. **样本方差无偏**：$\mathbb{E}[S^2] = \sigma^2$（这就是除以 n−1 的原因）

### 为什么除以 n−1？（直觉 + 证明要点）

**直觉**：用 $\bar{X}$ 替代 μ 时，n 个离差 $(X_i-\bar{X})$ 之和恒为 0，只有 n−1 个「自由」信息。除以 n 会系统性低估 σ²（因为 $\bar{X}$ 本身就在「追随」样本，$X_i-\bar{X}$ 平均比 $X_i-\mu$ 小）。

**证明要点**（完整推导见 [[估计量的评价标准：无偏性与一致性]] 附录）：

$$\mathbb{E}\left[\sum (X_i-\bar{X})^2\right] = (n-1)\sigma^2$$

所以除以 n 得 $(n-1)\sigma^2/n < \sigma^2$（低估），除以 n−1 恰好无偏。

## 5.3 三大抽样分布

### 5.3.1 卡方分布 $\chi^2_n$

**构造**：$Z_1,\dots,Z_n \sim N(0,1)$ i.i.d.，则 $\sum_{i=1}^n Z_i^2 \sim \chi^2_n$。

**性质**：
- $\mathbb{E}[\chi^2_n] = n$，$\mathrm{Var}(\chi^2_n) = 2n$
- 可加性：独立 $\chi^2_m + \chi^2_n \sim \chi^2_{m+n}$
- 右偏、非负；n 增大趋于对称

**🎯 面试考点——「自由度是什么？」**：自由度 = 独立信息的个数。$\chi^2_n$ 的自由度 n = 独立的平方项个数。为什么样本方差的自由度是 n−1？因为 $\bar{X}$ 吃掉了一个「自由度」（n 个离差有 1 个线性约束，和为零）。

### 5.3.2 t 分布 $t_n$

**构造**：$Z \sim N(0,1)$、$V \sim \chi^2_n$ 独立，则 $T = \dfrac{Z}{\sqrt{V/n}} \sim t_n$。

**性质**：
- 对称钟形，比正态**肥尾**（极端值更常见）
- $n \to \infty$ 时 $t_n \to N(0,1)$（尾巴变瘦）
- $\mathbb{E}[T]=0\ (n>1)$；$\mathrm{Var}(T)=\frac{n}{n-2}\ (n>2)$（方差比 1 大，印证肥尾）

**为什么肥尾？直觉**：分母 $\sqrt{V/n}$ 是随机的（≈1 但会波动），T 是「Z 除以一个随机放大倍数」——分母偶然很小时，T 就会很大，产生肥尾。样本小（n=5）时分母波动大，尾巴很肥；n=30 后分母接近 1，几乎正态。

**为什么小样本用 t？** 用样本标准差 s 替代 σ 引入了额外不确定性，正态近似忽略了这个不确定性会低估极端值概率——t 分布把这个不确定性算进去了。

### 5.3.3 F 分布 $F_{m,n}$

**构造**：$U \sim \chi^2_m$、$V \sim \chi^2_n$ 独立，则 $F = \dfrac{U/m}{V/n} \sim F_{m,n}$。

**性质**：
- 两个卡方（各自除以自由度）之比；非负、右偏
- **恒等式**：$T \sim t_n \Rightarrow T^2 \sim F_{1,n}$（t 的平方是 F）
- 用途：两方差比较（第 7 章 F 检验）、方差分析（第 8 章 ANOVA）

---

## 5.4 正态总体的三大关键结论

若 $X_1,\dots,X_n \sim N(\mu,\sigma^2)$ i.i.d.，则：

1. $\bar{X} \sim N(\mu,\ \sigma^2/n)$
2. $\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2_{n-1}$
3. **$\bar{X}$ 与 $S^2$ 相互独立**（正态特有！非正态不成立）

由 1、3 组合出 t 统计量：

$$\frac{\bar{X}-\mu}{S/\sqrt{n}} = \frac{Z}{\sqrt{\chi^2_{n-1}/(n-1)}} \sim t_{n-1}$$

**这就是 t 检验、t 置信区间的来源**。

**🎯 面试考点——「为什么 $\bar{X}$ 和 $S^2$ 独立让人惊讶？」**：直觉上均值变了，离差平方和也会变。但正态的特殊对称性使两者独立——这是正态分布独有的性质，也是「为什么 t 检验需要正态假设」的根本原因。非正态数据小样本下 t 检验可能失效。

## 💼 工作实战：抽样分布与 Bootstrap

### 解析抽样分布 vs Bootstrap

正态假设下，$\bar{X}$ 的抽样分布解析可求（$N(\mu,\sigma^2/n)$）。但统计量复杂（中位数、分位数、复杂指标）时解析分布很难求——**Bootstrap（自助法）**用「从样本中放回重抽样」近似抽样分布：

```python
import numpy as np
x = np.array([3.2, 4.1, 2.9, 5.0, 3.8, 4.4, 3.0])  # 观测样本
boot_means = [np.random.choice(x, len(x), replace=True).mean() for _ in range(10000)]
lo, hi = np.percentile(boot_means, [2.5, 97.5])
print(f"均值的 Bootstrap 95% CI ≈ [{lo:.2f}, {hi:.2f}]")
```

**原理**：重抽样分布是「经验分布」的抽样分布，大样本下逼近真实抽样分布。**用途**：中位数、比率、复杂指标（如 ARPU）的置信区间；不依赖正态假设。

### 用模拟验证 t 统计量

```python
from scipy import stats
# 模拟：从 N(5, 2) 抽 n=10 样本，计算 t 统计量，重复 10000 次
ts = [ (np.random.normal(5, np.sqrt(2), 10).mean() - 5) /
       (np.random.normal(5, np.sqrt(2), 10).std(ddof=1)/np.sqrt(10)) for _ in range(10000)]
# 与 t_9 理论密度对比（应吻合）
```

## 🎯 面试高频考点速览

1. **为什么除以 n−1？** 自由度损失 1（离差和为零），除以 n 系统性低估方差。
2. **三大分布怎么造？** 标准正态平方和 → χ²；χ² 开方比值 → t；χ² 之比 → F。
3. **t 分布为什么肥尾？** 分母随机波动，偶尔产生大值；n→∞ 趋于正态。
4. **为什么小样本用 t 不用 Z？** s 替代 σ 引入不确定性，t 分布把它算进去。
5. **X̄ 与 S² 为什么独立？** 正态特有性质，是 t 检验的前提。
6. **Bootstrap 是什么？** 从样本放回重抽样，用经验分布近似总体，估计统计量的抽样分布。

## 练习（含解答）

**练 1**：$X_1,\dots,X_{16} \sim N(100, 64)$。求 $\bar{X}$ 的分布与 $P(\bar{X} < 96)$。

解：$\bar{X}\sim N(100, 64/16)=N(100,4)$，$P(\bar{X}<96)=P(Z<-2)\approx0.0228$。

**练 2**：$X_1,\dots,X_9 \sim N(0,1)$。求 $P(\sum X_i^2 \le 16.9)$ 的分布类型。

解：$\sum X_i^2 \sim \chi^2_9$，$P(\chi^2_9 \le 16.9)\approx0.95$（查表）。

**练 3**：$X_1,\dots,X_n \sim N(\mu,\sigma^2)$，构造 $T=\frac{\bar{X}-\mu}{S/\sqrt{n}}$ 的分布。

解：$T \sim t_{n-1}$——分子标准化 $Z\sim N(0,1)$，分母由 $(n-1)S^2/\sigma^2 \sim \chi^2_{n-1}$ 得到，两者独立（正态结论 3）。

**练 4（面试常考）**：$n=25$，$s=10$，求 $\sigma^2$ 的 95% 置信区间。

解：$\frac{24S^2}{\sigma^2}\sim\chi^2_{24}$，$\chi^2_{24,0.975}\approx12.4$，$\chi^2_{24,0.025}\approx39.4$，区间 $[24\times100/39.4,\ 24\times100/12.4]=[60.9,\ 193.5]$。

**练 5（概念）**：为什么中位数的抽样分布不能直接用正态结论？

解：中位数不是正态样本的线性函数，三大结论只对 $\bar{X}$ 和 $S^2$ 这类统计量成立；中位数要用渐近理论（第 9 章）或 Bootstrap。
