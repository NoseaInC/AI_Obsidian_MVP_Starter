# 06 参数估计（教材版）

> 学完本章你将能：用矩估计与极大似然估计（MLE）手推常见分布的参数估计；用无偏性、有效性、一致性三个标准评价估计量；理解 MLE 的渐近性质（一致、渐近正态、有效）；掌握枢轴量法构造置信区间；会算单/双正态总体与比例的置信区间；理解置信区间的正确解读（重复抽样意义，而非参数落入区间的概率）。

## 学习目标

1. 掌握矩估计的思想与步骤（样本矩碰总体矩）；
2. 掌握 MLE 的思想、步骤与不变性；
3. 能用无偏/有效/一致评价估计量，理解 CR 下界与 Fisher 信息；
4. 理解枢轴量法构造置信区间的四步套路；
5. 会写单正态总体均值/方差的置信区间；
6. 会写两总体均值差、方差比的置信区间；
7. 会用大样本（CLT）做比例的置信区间；
8. 能正确解读置信区间（关键概念）。

## 6.0 引言：参数估计的两层任务

总体分布未知，但我们假设它属于某个「带参数的分布族」：比如 $N(\mu,\sigma^2)$ 或 $\mathrm{Bernoulli}(p)$。

- **点估计**：给参数一个最佳猜测（μ 的估计 = ？）
- **区间估计**：给参数一个「合理范围」（μ 大概在 [a, b] 之间）

区间估计比点估计更有用：它同时表达了「估计在哪」和「估计有多不确定」。

---

## 6.1 点估计：矩估计法（MoM）

### 思想

总体的矩是参数的函数（如 $\mathbb{E}[X]=\theta/2$），样本矩是总体矩的自然估计（LLN 保证收敛）。令「样本矩 = 总体矩」，解方程得到参数估计。

### 步骤

1. 计算总体一阶矩 $\mathbb{E}[X]$（必要时二阶矩 $\mathbb{E}[X^2]$）与参数的关系；
2. 令 $\bar{X} = \mathbb{E}[X]$（必要时再令 $\frac{1}{n}\sum X_i^2 = \mathbb{E}[X^2]$）；
3. 解方程得 $\hat\theta$。

**例（均匀分布 $U(0,\theta)$）**：$\mathbb{E}[X]=\theta/2$。令 $\bar{X}=\theta/2$，得 $\hat\theta_{MoM} = 2\bar{X}$。

**例（正态 $N(\mu,\sigma^2)$）**：$\hat\mu = \bar{X}$，$\hat\sigma^2 = \frac{1}{n}\sum(X_i-\bar{X})^2$（注意这里除 n，与第 5 章的无偏版本差一个因子）。

**优点**：永远能算、简单。**缺点**：不一定最优（方差可能大）；对某些分布（如柯西）矩不存在。

---

## 6.2 点估计：极大似然估计（MLE）

### 思想

选择「使观测到的数据出现概率最大」的参数值。

### 步骤

1. 写似然函数 $L(\theta)=\prod_{i=1}^n f(x_i;\theta)$；
2. 取对数（乘积变求和，方便求导）$\ell(\theta)=\ln L(\theta)$；
3. 解 $\ell'(\theta)=0$，验证二阶导为负；
4. 得 $\hat\theta_{MLE}$。

**例（伯努利/二项）**：$L(p)=p^k(1-p)^{n-k}$，$\ell(p)=k\ln p+(n-k)\ln(1-p)$。求导：$\frac{k}{p}-\frac{n-k}{1-p}=0$，得 $\hat p = k/n$——成功的比例，直觉合理。

**例（正态）**：$\ell(\mu,\sigma^2)=-\frac{n}{2}\ln(2\pi\sigma^2)-\frac{1}{2\sigma^2}\sum(x_i-\mu)^2$。对 μ 求导得 $\hat\mu=\bar{X}$；对 σ² 求导得 $\hat\sigma^2=\frac{1}{n}\sum(x_i-\bar{X})^2$。

**例（均匀分布 $U(0,\theta)$）**：$L(\theta)=\theta^{-n}$（对 $\theta \ge \max x_i$）。$
L$ 随 θ 递减，所以在约束下取**最小可行** θ：$\hat\theta_{MLE}=\max_i X_i$。注意：MLE 不是靠求导得到的，是靠「可行域边界」——这是 MLE 与矩估计（$2\bar{X}$）不同的经典例子。

**不变性**：若 $\hat\theta$ 是 MLE，则 $g(\hat\theta)$ 是 $g(\theta)$ 的 MLE（任意函数 g）。例：$\hat\sigma_{MLE}=\sqrt{\hat\sigma^2_{MLE}}$。

**🎯 面试考点——「矩估计和 MLE 什么区别？什么时候相同？」**：MoM 简单但效率低；MLE 渐近最优。正态下两者相同（$\bar{X}$、$\frac1n\sum(X_i-\bar{X})^2$）；$U(0,\theta)$ 下不同（$2\bar{X}$ vs $\max X_i$），且 MLE 的 $\max X_i$ 比 $2\bar{X}$ 方差更小。

## 6.3 估计量的评价：无偏、有效、一致

| 标准 | 定义 | 问题 |
|---|---|---|
| 无偏性 | $\mathbb{E}[\hat\theta]=\theta$ | 有限样本下系统不骗我？ |
| 有效性 | 无偏估计中方差最小 | 同样无偏，谁更稳？ |
| 一致性 | $\hat\theta_n \xrightarrow{P} \theta$ | 样本越大越准？ |

### CR 下界与 Fisher 信息

正则条件下，任何无偏估计的方差有下界：

$$\mathrm{Var}(\hat\theta) \ge \frac{1}{n\,I(\theta)}$$

其中 Fisher 信息 $I(\theta) = -\mathbb{E}\left[\frac{\partial^2}{\partial\theta^2}\ln f(X;\theta)\right]$。

**直觉**：$I(\theta)$ 越大 = 似然曲面越「尖」= 数据对参数越敏感 = 估计可以越准。

**例**：伯努利 $I(p)=\frac{1}{p(1-p)}$，CR 下界 $=\frac{p(1-p)}{n}$，而 $\hat p$ 的方差恰好 $=\frac{p(1-p)}{n}$——达到下界，$\hat p$ 是有效估计。

**🎯 面试考点——「无偏估计一定比有偏估计好吗？」**：不一定。无偏性只是「平均不偏」，可能方差巨大；有偏但方差小的估计（如岭回归、正则化估计）在实际预测中往往 MSE 更小。MSE = 偏差² + 方差。

> 详细比较（含四种组合表格）见 [[估计量的评价标准：无偏性与一致性]]。

## 6.4 区间估计：枢轴量法

### 枢轴量的定义

样本与参数的函数 $Q(X_1,\dots,X_n;\theta)$，其**分布已知且不含未知参数**。

**例**：正态总体 $\frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t_{n-1}$（μ 是未知参数，但整个量的分布是固定的 $t_{n-1}$）——所以它是枢轴量。

### 四步套路

1. 找枢轴量 $Q$（分布已知）；
2. 写 $P(a \le Q \le b) = 1-\alpha$（a、b 是分布的 $\alpha/2$、$1-\alpha/2$ 分位数）；
3. 把括号里的不等式反解成「参数在区间内」；
4. 得置信区间 $[\hat\theta_L, \hat\theta_U]$。

**⚠️ 置信区间的正确解读（面试必考）**：
- ✅ 正确：重复抽样 100 次，约 95 次的区间会盖住 μ（区间是随机的，参数是固定的）。
- ❌ 错误：μ 有 95% 概率落在这个区间里（参数是固定常数，没有概率分布）。

---

## 6.5 单正态总体的置信区间

| 参数 | 条件 | 区间 |
|---|---|---|
| μ | σ 已知 | $\bar{X} \pm z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}}$ |
| μ | σ 未知 | $\bar{X} \pm t_{n-1,\alpha/2}\,\frac{S}{\sqrt{n}}$ |
| σ² | μ 未知 | $\left[\frac{(n-1)S^2}{\chi^2_{1-\alpha/2}},\ \frac{(n-1)S^2}{\chi^2_{\alpha/2}}\right]$ |

**例（奶茶容量）**：测 16 杯，$\bar{x}=498$ ml，$s=6$ ml。μ 的 95% CI：$498 \pm t_{15,0.025}\frac{6}{4}=498\pm2.131\times1.5=[494.8,\ 501.2]$。若声称「每杯至少 500ml」，500 在区间内，证据不足。

---

## 6.6 两正态总体的置信区间

**均值差（σ 未知但相等，合并方差）**：

$$\bar{X}-\bar{Y} \pm t_{n_1+n_2-2,\alpha/2}\, s_p \sqrt{\frac{1}{n_1}+\frac{1}{n_2}}$$

**方差比**：$\left[\frac{S_1^2/S_2^2}{F_{n_1-1,n_2-1,\alpha/2}},\ \frac{S_1^2/S_2^2}{F_{n_1-1,n_2-1,1-\alpha/2}}\right]$（利用 $\frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}\sim F_{n_1-1,n_2-1}$）。

**例（A/B 测试雏形）**：对照组 $\bar{x}=0.042,\ s_1=0.20,\ n_1=1000$；实验组 $\bar{y}=0.050,\ s_2=0.22,\ n_2=1000$。95% CI for 转化率差：

$$0.008 \pm 1.96\sqrt{\frac{0.042\times0.958}{1000}+\frac{0.050\times0.950}{1000}} \approx 0.008 \pm 0.0175 = [-0.0095,\ 0.0255]$$

区间含 0 → 差异不显著（第 7 章用假设检验严格判断）。

---

## 6.7 大样本（非正态）的区间估计

**比例**：$\hat p \approx N(p,\ p(1-p)/n)$，区间

$$\hat p \pm z_{\alpha/2}\,\sqrt{\frac{\hat p(1-\hat p)}{n}}$$

**任意总体均值（n 大）**：CLT 保证 $\bar{X}\approx N(\mu,\sigma^2/n)$，用 s 替代 σ：$\bar{X}\pm z_{\alpha/2}\,\frac{s}{\sqrt{n}}$（大样本时 t≈z）。

**例（满意度）**：500 人调查，满意率 $\hat p=0.6$。95% CI：$0.6\pm1.96\sqrt{0.6\times0.4/500}=0.6\pm0.0429=[0.557,\ 0.643]$。

## 💼 工作实战：置信区间在业务中的用法

### A/B 测试的区间思维

不要只看「转化率 5.0% > 4.2%」，要看**差异的置信区间**：若 95% CI 不包含 0 才算「显著」。

```python
import numpy as np
from statsmodels.stats.proportion import proportion_confint
# 实验组 50/1000，对照组 42/1000
ci_t = proportion_confint(50, 1000, alpha=0.05)
ci_c = proportion_confint(42, 1000, alpha=0.05)
print(ci_t, ci_c)
```

### 业务指标波动判断

DAU、GMV 波动时，先看波动是否在「随机波动范围」（均值 ± 2 倍标准差）内，再决定是否告警/干预——避免对噪声做反应。

### 统计软件中的 CI

sklearn 的 `LinearRegression` 默认不给 CI，但 `statsmodels` 的 `summary()` 直接输出系数的 95% CI；`scipy.stats.t.interval` 可手算。面试里「如何给模型系数算置信区间」= 考第 5 章 t 分布 + 本章枢轴量法。

## 🎯 面试高频考点速览

1. **MLE 步骤？** 写似然 → 取对数 → 求导 = 0 → 得估计。
2. **U(0,θ) 的 MLE？** $\max X_i$（边界最优，不是求导）。
3. **MoM 与 MLE 区别？** MoM 简单低效，MLE 渐近最优；正态相同，U(0,θ) 不同。
4. **MLE 三个渐近性质？** 一致、渐近正态（方差 = Fisher 信息倒数）、渐近有效。
5. **置信区间怎么解读？** 重复抽样约 95% 区间覆盖参数；参数不是随机变量。
6. **无偏一定最好吗？** 不一定；MSE = 偏差² + 方差，正则化常有偏但 MSE 更小。

## 练习（含解答）

**练 1**：$X_1,\dots,X_n \sim \mathrm{Exp}(\lambda)$。求 λ 的矩估计与 MLE。

解：$\mathbb{E}[X]=1/\lambda$，矩估计 $\hat\lambda_{MoM}=1/\bar{X}$。似然 $L=\lambda^n e^{-\lambda\sum x_i}$，$\ell=n\ln\lambda-\lambda\sum x_i$，$\ell'=n/\lambda-\sum x_i=0$，$\hat\lambda_{MLE}=1/\bar{X}$——本例相同。

**练 2**：$X_1,\dots,X_n \sim U(0,\theta)$。比较 $2\bar{X}$ 与 $\max X_i$ 的无偏性。

解：$\mathbb{E}[2\bar{X}]=\theta$ 无偏；$\mathbb{E}[\max X_i]=\frac{n}{n+1}\theta$ 有偏（低估），修正后 $\frac{n+1}{n}\max X_i$ 无偏。

**练 3**：n=25，$\bar{x}=110$，$s=15$。求 μ 的 95% CI（σ 未知）。

解：$110\pm t_{24,0.025}\frac{15}{5}=110\pm2.064\times3=[103.8,\ 116.2]$。

**练 4**：400 人中 280 人喜欢新品。求比例的 95% CI。

解：$\hat p=0.7$，$0.7\pm1.96\sqrt{0.7\times0.3/400}=0.7\pm0.0449=[0.655,\ 0.745]$。

**练 5（面试）**：解释「95% 置信区间」到底是什么意思。

解：反复从同一总体抽样本、每次都算区间，长期看约 95% 的区间包含真实参数。对已经算出来的一个具体区间，只能说它「属于那 95% 的概率是 95%」——更严谨地说：置信度是过程的性质，不是单个区间的性质。
