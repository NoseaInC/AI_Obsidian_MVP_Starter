# 04 数字特征与极限定理（教材版）

> 学完本章你将能：熟练计算期望、方差与矩并理解其业务含义；用切比雪夫不等式做「不依赖分布」的概率界；深刻理解大数定律（样本均值收敛到总体均值）与中心极限定理（样本均值近似正态）的区别与联系；把蒙特卡洛模拟、3σ 异常检测、样本量估算用到数据科学工作中。

## 学习目标

1. 掌握期望与方差的定义、计算与性质（含「期望线性无需独立」这一关键点）；
2. 会用切比雪夫不等式及其推论（3σ 界、大数定律证明）；
3. 区分弱大数律与强大数律，理解各自条件；
4. 掌握 CLT 及其推论（样本均值的近似分布）；
5. 理解 LLN 与 CLT 的关系：LLN 给「中心」，CLT 给「散布」；
6. 会设计蒙特卡洛模拟并估计其误差。

---

## 4.0 引言：分布太「胖」，需要数字

一个分布用密度/分布律描述最完整，但有时我们只想知道「平均水平」和「波动大小」。

- 投资：A 基金年化 8% ± 15% vs B 基金 5% ± 3%——只看分布太繁琐，两个数字就够决策
- 监控：服务延迟「平均 80ms，波动 20ms」——均值和标准差是 SLA 的通用语言

**期望压缩位置信息，方差压缩离散信息**。它们是分布的两个「摘要统计量」。

---

## 4.1 数学期望

### 定义

- 离散：$\mathbb{E}[X] = \sum_k x_k\, p_k$
- 连续：$\mathbb{E}[X] = \int_{-\infty}^{\infty} x\, f(x)\,dx$

**直觉**：长期平均——重复试验无穷多次，结果的平均值。

**例（投资决策）**：A 有 50% 概率赚 20%、50% 概率亏 10%；B 确定赚 3%。

$$\mathbb{E}[A] = 0.5\times20\% + 0.5\times(-10\%) = 5\%, \qquad \mathbb{E}[B] = 3\%$$

期望上 A 更优，但风险完全不同——这正是方差要补充的信息。

### 期望的线性性质（关键！）

$$\mathbb{E}[aX + bY + c] = a\mathbb{E}[X] + b\mathbb{E}[Y] + c$$

**对任意 X、Y 成立，不要求独立！** 这是「样本均值无偏性」的直接依据（第 6 章）。

**🎯 面试考点——「为什么期望线性不需要独立，方差可加却需要？」**：期望是加权平均，线性性是求和/积分算子的内在性质；方差涉及 $\mathbb{E}[XY]$，只有当 $X,Y$ 独立（或不相关）时 $\mathbb{E}[XY]=\mathbb{E}[X]\mathbb{E}[Y]$，交叉项才消失。

### 期望与函数

$\mathbb{E}[g(X)] = \sum g(x_k)p_k$（离散）或 $\int g(x)f(x)dx$（连续）——**不能**写成 $g(\mathbb{E}[X])$！

**例**：$X$ 等概率取 {1,3}，$\mathbb{E}[X^2] = (1+9)/2 = 5$，但 $(\mathbb{E}[X])^2 = 4$。两者不同——记住：期望不穿函数（除非函数线性）。

## 4.2 方差与矩

### 方差定义

$$\mathrm{Var}(X) = \mathbb{E}[(X-\mathbb{E}[X])^2] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$$

第二个等式（计算用）由 $\mathbb{E}[X^2 - 2X\mathbb{E}[X] + (\mathbb{E}[X])^2]$ 展开即得。

**性质**：
- $\mathrm{Var}(aX+b) = a^2\mathrm{Var}(X)$（平移不变、缩放平方）
- 独立时 $\mathrm{Var}(X+Y) = \mathrm{Var}(X)+\mathrm{Var}(Y)$（不独立要加 $2\mathrm{Cov}$）

**例（接上）**：A 的方差 $= 0.5(0.2-0.05)^2 + 0.5(-0.1-0.05)^2 = 0.0225$，标准差 15%；B 标准差 0。期望 A 高但波动剧烈——风险偏好决定选择。

### 矩

$k$ 阶原点矩 $\mu_k' = \mathbb{E}[X^k]$；$k$ 阶中心矩 $\mu_k = \mathbb{E}[(X-\mathbb{E}[X])^k]$。

- 期望 = 一阶原点矩，方差 = 二阶中心矩
- 三阶中心矩 → 偏度（skewness），四阶 → 峰度（kurtosis）——**分布形状的数字描述**

**💼 工作实战——偏度峰度检查**：建模前检查特征分布：

```python
import scipy.stats as st
skew, kurt = st.skew(x), st.kurtosis(x)  # 偏度 ≠ 0 提示非对称；峰度 > 0 提示厚尾
```

严重右偏（如收入）→ 对数变换；厚尾（如金融收益）→ 不能用正态假设。

## 4.3 切比雪夫不等式

对任意 $\varepsilon > 0$（只要求方差存在，不依赖分布形状）：

$$P\bigl(|X - \mathbb{E}[X]| \ge \varepsilon\bigr) \le \frac{\mathrm{Var}(X)}{\varepsilon^2}$$

### 证明（教材标准推导，面试可复述）

令 $Y = (X-\mathbb{E}[X])^2$。对事件 $Y \ge \varepsilon^2$，有 $Y \ge \varepsilon^2 \cdot \mathbb{1}\{Y \ge \varepsilon^2\}$，取期望：

$$\mathrm{Var}(X) = \mathbb{E}[Y] \ge \varepsilon^2\, P(Y \ge \varepsilon^2) = \varepsilon^2\, P(|X-\mathbb{E}[X]| \ge \varepsilon)$$

移项即得。

### 三个常用推论

取 $\varepsilon = k\sigma$：$P(|X-\mu| \ge k\sigma) \le 1/k^2$。

- $k=2$：至少 75% 的数据在 $\mu \pm 2\sigma$ 内（对任何分布！）
- $k=3$：至少 88.9% 在 $\mu \pm 3\sigma$ 内
- **注意**：切比雪夫是「最坏情况」界；正态下 $\mu\pm2\sigma$ 覆盖约 95%，远好于 75%。所以正态时别用切比雪夫，它太松。

**🎯 面试考点——「切比雪夫不等式有什么用？」**：不假设分布，只用均值和方差就能给出概率界。用它证明大数定律、做「无分布假设」的保守估计（如：不知道分布时，说至少 75% 在 2σ 内是安全的）。

## 4.4 大数定律（LLN）

**核心结论**：样本均值 $\bar{X}_n$ 依概率收敛于总体均值 $\mu$。

### 弱大数律（依概率收敛）

对任意 $\varepsilon>0$：$\displaystyle\lim_{n\to\infty} P(|\bar{X}_n - \mu| \ge \varepsilon) = 0$。

### 强大数律（几乎处处收敛）

$P\left(\lim_{n\to\infty} \bar{X}_n = \mu\right) = 1$——几乎每条样本路径最终都稳定在 μ 附近，比弱大数律更强。

### 切比雪夫大数定律（证明骨架）

条件：独立、方差有公共上界 $\mathrm{Var}(X_i) \le C$。

$$P(|\bar{X}_n-\mu| \ge \varepsilon) \le \frac{\mathrm{Var}(\bar{X}_n)}{\varepsilon^2} = \frac{\sigma^2/n}{\varepsilon^2} \to 0$$

这里用了 $\mathrm{Var}(\bar{X}_n) = \sigma^2/n$（独立方差可加 + 除以 n 平方缩放）。

### 辛钦大数定律（更弱条件）

i.i.d. + 期望存在（方差可以不存在，如柯西分布除外——柯西连期望都不存在）。

**⚠️ 柯西分布陷阱**：$X \sim \mathrm{Cauchy}$ 期望不存在，$\bar{X}_n$ 不收敛（每次平均还是柯西）。大数定律的「期望存在」不是可有可无的条件！

> 更完整的推导见 [[大数定律与中心极限定理]]。

## 4.5 中心极限定理（CLT）

### 林德伯格-莱维定理

$X_1,\dots,X_n$ i.i.d.，$\mathbb{E}[X_i]=\mu$，$\mathrm{Var}(X_i)=\sigma^2<\infty$，则

$$\frac{\sqrt{n}(\bar{X}_n - \mu)}{\sigma} \xrightarrow{d} N(0,1)$$

等价近似：$\bar{X}_n \approx N\left(\mu,\ \frac{\sigma^2}{n}\right)$。

**直觉**：不管原始分布长什么样（偏态、离散、双峰…），大量独立随机量之和/均值都趋于正态——正态「无处不在」的数学原因。

### 三个推论（工作中直接使用）

1. **求和近似**：$S_n = \sum X_i \approx N(n\mu,\ n\sigma^2)$
2. **比例近似**：$\hat p = \frac{S_n}{n} \approx N\left(p,\ \frac{p(1-p)}{n}\right)$（二项比例的 CLT，第 7 章 Z 检验基础）
3. **3σ 法则**：$\bar{X}_n$ 以约 95% 概率落在 $\mu \pm 2\sigma/\sqrt{n}$

**例（误差叠加）**：每次测量误差 $\sim U(-0.5, 0.5)$（标准差 $\approx 0.289$），n=100 次平均误差的标准差 $= 0.289/10 \approx 0.029$——多测几次取平均能把误差压到很小，这是「重复测量提高精度」的数学原理。

**例（比例估计）**：民调抽样 n=1000 人，真实支持率 p=0.5，$\hat p$ 的标准差 $= \sqrt{0.5\times0.5/1000} \approx 1.58\%$——「1000 人抽样误差约 ±3%」就是这么来的（$1.96\times1.58\%\approx3.1\%$）。

## 💼 工作实战：极限定理的三类应用

### 1. 蒙特卡洛模拟（LLN 的化身）

用随机模拟估计难以解析计算的量。**蒙特卡洛估计 π**：单位正方形随机投点，落在四分之一圆内比例 $\hat p \to \pi/4$，所以 $4\hat p \approx \pi$。

```python
import numpy as np
n = 1_000_000
x, y = np.random.rand(n), np.random.rand(n)
pi_hat = 4 * ((x**2 + y**2) <= 1).mean()
print(f"π 估计 = {pi_hat:.4f}（误差约 {abs(pi_hat-np.pi):.4f}）")
```

**误差分析（CLT 给）**：$\hat p$ 的标准差 $\approx \sqrt{p(1-p)/n}$，误差随 $1/\sqrt{n}$ 衰减——想精度翻倍，样本量要 ×4。

### 2. 异常检测（3σ 法则）

监控指标（延迟、错误率、DAU）近似正态时，超出 $\mu+3\sigma$ 触发告警。但注意：**厚尾数据（幂律、金融）用 3σ 会频繁误报**，应改用分位数（P99）或稳健方法。

### 3. 样本量估算

目标：把估计误差控制在 $\pm e$ 内，置信 95%。由 CLT，需要 $1.96\,\sigma/\sqrt{n} \le e$，即 $n \ge (1.96\sigma/e)^2$。

**例**：想以 ±2% 精度（e=0.02）估计转化率（σ≈0.5 最保守），$n \ge (1.96\times0.5/0.02)^2 \approx 2401$ 人。

## 🎯 面试高频考点速览

1. **期望线性需要独立吗？** 不需要；方差可加需要（不相关即可）。
2. **$\mathbb{E}[g(X)] = g(\mathbb{E}[X])$ 成立吗？** 不成立（g 非线性时），用 $\int g(x)f(x)dx$。
3. **切比雪夫的意义？** 只用均值方差的无分布概率界；正态时偏松。
4. **LLN 和 CLT 的区别？** LLN：$\bar{X}_n$ 收敛到 μ（点）；CLT：$\sqrt{n}(\bar{X}_n-\mu)/\sigma$ 的分布趋于正态（分布）。LLN 给中心，CLT 给散布。
5. **为什么柯西分布不能用大数定律？** 期望不存在，平均值不收敛。
6. **蒙特卡洛误差怎么减小？** 样本量 ×4 误差减半（$1/\sqrt{n}$）。
7. **民调 1000 人误差约 ±3% 怎么来的？** $1.96\sqrt{p(1-p)/1000}\approx3\%$。

## 练习（含解答）

**练 1**：$X$ 分布律：$P(X=-1)=0.2, P(X=0)=0.5, P(X=2)=0.3$。求 $\mathbb{E}[X]$、$\mathrm{Var}(X)$。

解：$\mathbb{E}[X] = -0.2+0+0.6=0.4$。$\mathbb{E}[X^2]=0.2+0+1.2=1.4$，$\mathrm{Var}=1.4-0.16=1.24$。

**练 2**：用切比雪夫给出 $P(|X-\mu|\ge 2.5\sigma)$ 的上界，并和正态比较。

解：$\le 1/6.25 = 16\%$；正态实际约 1.2%——切比雪夫对任意分布安全但粗糙。

**练 3**：掷骰子 n 次，点数和 $S_n$。用 CLT 求 $P(S_{100} \ge 380)$ 的近似。

解：单次 $\mu=3.5$，$\sigma^2=35/12$。$S_{100}\approx N(350,\ 291.67)$，$P(S\ge380)=P(Z\ge30/17.08)\approx P(Z\ge1.76)\approx0.039$。

**练 4**：某 App 次日留存率真实 p=0.4，抽样 n=2500 用户。$\hat p$ 的 95% 波动范围？

解：$\mathrm{SD}=\sqrt{0.4\times0.6/2500}=0.0098$，约 $\hat p \in 0.4 \pm 1.96\times0.0098 = [0.381, 0.419]$。

**练 5**：设计蒙特卡洛估计 $\int_0^1 e^{-x^2}dx$。

解：$\mathbb{E}[e^{-U^2}]=\int_0^1 e^{-x^2}dx$，所以生成 U~U(0,1) 大量样本取平均即可；误差 $\approx \mathrm{SD}/\sqrt{n}$。
