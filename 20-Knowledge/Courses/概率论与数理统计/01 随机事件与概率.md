# 01 随机事件与概率（教材版）

> 本章是全课程的地基。学完后你将能：用集合语言描述随机事件并熟练运算；理解概率的三种定义与公理化体系；掌握条件概率、独立性、全概率公式与贝叶斯公式并能独立计算；把这些工具用到数据科学的真实场景（随机模拟、朴素贝叶斯、混淆矩阵）。

## 学习目标

1. 区分随机现象与确定性现象，写出常见试验的样本空间；
2. 用事件运算（并、交、补、差）描述复杂条件，掌握德摩根律；
3. 理解古典、几何、频率、公理化四种概率定义及其适用场景；
4. 掌握条件概率与独立性，能识别并避免「把条件概率搞反」的错误；
5. 会用全概率公式和贝叶斯公式解决「由果溯因」问题；
6. 理解伯努利概型，能计算 n 重伯努利试验的概率。

---

## 1.0 引言：为什么要学概率？

数据科学处理的几乎一切问题都带着不确定性：

- A/B 测试：新版页面的转化率 4.2% 真的比旧版 3.8% 高吗？还是随机波动？
- 风控：一个用户的违约概率是多少？
- 推荐系统：用户点击某条推荐的「概率」怎么估计？
- 大模型：下一个 token 的输出本身就是概率分布。

**概率论是「不确定性的数学语言」**：它把「我猜明天会下雨」这种模糊表述，变成「P(明天下雨)=0.7」这种可以计算、可以检验、可以决策的精确命题。本章教你这种语言的字母表（事件）和语法（概率的公理与公式）。

## 1.1 随机现象与样本空间

### 两类现象

- **确定性现象**：条件相同则结果唯一。水在标准大气压下 100°C 沸腾。
- **随机现象**：条件相同，结果却可能不同。掷一枚硬币可能是正也可能是反。

> 注意：随机 ≠ 无法预测。随机是指「单次结果不确定，但大量重复后呈现出稳定规律」。这个「稳定的规律」正是概率要刻画的。

### 基本术语

| 术语 | 含义 | 例子 |
|---|---|---|
| 随机试验 | 可重复、结果不唯一、事先不知结果的观察过程 | 掷骰子、抽检产品、记录呼叫中心来电数 |
| 样本点 $\omega$ | 一次试验的**单个**可能结果 | 「掷出 3 点」 |
| 样本空间 $\Omega$ | 所有样本点的集合 | $\{1,2,3,4,5,6\}$ |
| 随机事件 | $\Omega$ 的**子集**（一组结果） | 「掷出偶数」= $\{2,4,6\}$ |

### 常见样本空间

**例 1（掷骰子）**：$\Omega = \{1,2,3,4,5,6\}$，有限。

**例 2（抛硬币两次）**：注意顺序是有信息的，$\Omega = \{HH, HT, TH, TT\}$。若写成 $\{HH, HT, TT\}$ 就错了——「一正一反」对应两个样本点 $HT, TH$，概率是 $2/4$ 而不是 $1/3$。

**例 3（产品寿命）**：$\Omega = [0, \infty)$，连续。

**例 4（呼叫中心来电数）**：$\Omega = \{0, 1, 2, \dots\}$，可数无穷。

> **数科直觉**：样本空间就是「所有可能的世界」。你之后写的模拟代码，本质就是让计算机在样本空间里大量「抽签」。

## 1.2 随机事件及其运算

### 事件的关系

| 关系 | 记号 | 含义 | 骰子例子 |
|---|---|---|---|
| 包含 | $A \subset B$ | A 发生则 B 必发生 | 「掷出6」⊂「掷出偶数」 |
| 相等 | $A = B$ | 互为包含 | 「掷出奇数」=「掷出 1 或 3 或 5」 |
| 互斥 | $A \cap B = \varnothing$ | 不能同时发生 | 「掷出偶数」与「掷出奇数」 |
| 对立 | $\bar A$ | 恰好不发生 A | 「掷出偶数」的对立是「掷出奇数」 |

### 事件的运算

| 运算 | 记号 | 含义 | 例子（A=偶数，B=大于4） |
|---|---|---|---|
| 并 | $A \cup B$ | A 或 B 至少一个发生 | $\{2,4,6,5\}$ |
| 交 | $A \cap B$ | A 和 B 同时发生 | $\{6\}$ |
| 补 | $\bar A$ | A 不发生 | $\{1,3,5\}$ |
| 差 | $A - B$ | A 发生而 B 不发生 | $\{2,4\}$ |

### 德摩根律（最常考、最常错）

$$\overline{A \cup B} = \bar A \cap \bar B, \qquad \overline{A \cap B} = \bar A \cup \bar B$$

**直觉（不要死记）**：「并非（A 或 B）」=「A 没发生 **且** B 也没发生」；「并非（A 且 B）」=「A 没发生 **或** B 没发生」。

**例子**：A=「今天下雨」，B=「我迟到」。

- $\overline{A \cup B}$ =「既没下雨也没迟到」；
- $\overline{A \cap B}$ =「至少有一件没发生」（没下雨，或没迟到，或两者都）。

> **数科直觉**：德摩根律就是「或」与「且」的补集互换。写 SQL/代码时，`NOT (A OR B)` 等价于 `(NOT A) AND (NOT B)`，很多 bug 都出在这里。

## 1.3 概率的定义：四种视角

### 1.3.1 古典概型

**适用条件**：$\Omega$ 有限，且每个样本点等可能。

$$P(A) = \frac{|A|}{|\Omega|} = \frac{\text{有利结果数}}{\text{总结果数}}$$

**核心计数工具**：
- 乘法原理：做一件事分 $k$ 步，每步 $n_i$ 种选择，共 $n_1 n_2 \cdots n_k$ 种。
- 排列：$P_n^k = \dfrac{n!}{(n-k)!}$（有序）
- 组合：$\binom{n}{k} = \dfrac{n!}{k!(n-k)!}$（无序）

**例 1（掷两颗骰子）**：求点数和为 7 的概率。

总结果 $6 \times 6 = 36$。和为 7 的有序组合：(1,6),(2,5),(3,4),(4,3),(5,2),(6,1) 共 6 种。

$$P = \frac{6}{36} = \frac{1}{6} \approx 0.167$$

> 容易错：把 (1,6) 和 (6,1) 当成同一种。它们是**不同的样本点**（两颗骰子可区分），必须分开数。

**例 2（生日问题，数据科学必知）**：n 个人中至少有两人生日相同的概率是多少？

思路：先算「全都不同」的补事件。第 1 人任意；第 2 人与第 1 人不同：$364/365$；第 3 人不同：$363/365$；……

$$P(\text{至少两人相同}) = 1 - \frac{365 \cdot 364 \cdots (365-n+1)}{365^n}$$

代入计算：$n=23$ 时约 **0.507**（超过一半！）；$n=50$ 时约 0.97。

> **数科直觉**：生日问题揭示「碰撞概率」上升得远比直觉快。这正是哈希碰撞、随机抽样重复率、缓存冲突的理论根源——也是为什么大数据集里「以为不会重复」的键其实很容易撞车。

### 1.3.2 几何概型

**适用条件**：样本点是某个区域（线段、平面、空间）中的点，等可能落在区域内。

$$P(A) = \frac{\text{区域 A 的测度（长度/面积/体积）}}{\text{整个区域的测度}}$$

**例（会面问题）**：两人约定 9:00–10:00 之间到达某地，先到者等 10 分钟。求两人能见面的概率。

设两人到达时刻为 $(X,Y)$，样本空间是 $60 \times 60$ 的正方形，等可能。能见面 ⇔ $|X - Y| \le 10$，即落在两条对角线 $Y = X \pm 10$ 之间的带状区域。

$$P = \frac{60^2 - 50^2}{60^2} = \frac{1100}{3600} = \frac{11}{36} \approx 0.306$$

> 几何概型是「连续型随机变量」（第 2 章）的直观前身：概率变成了面积比。

### 1.3.3 频率定义（统计概率）

做 $n$ 次重复试验，记 $n_A$ 为 A 发生的次数，则 $P(A)$ 是频率 $n_A/n$ 在 $n \to \infty$ 时的稳定值。

**例（抛硬币模拟）**：抛 10 次可能正面频率 0.6，抛 1000 次可能 0.512，抛 10 万次几乎肯定接近 0.5。

> 这个「频率趋稳」现象不是假设，而是**大数定律**（第 4 章）保证的定理。届时你会看到严格的数学证明。

### 1.3.4 公理化定义（Kolmogorov）

概率是定义在事件上的函数 $P$，满足三条公理：

1. **非负性**：$0 \le P(A) \le 1$；
2. **规范性**：$P(\Omega) = 1$；
3. **可列可加性**：对两两互斥的事件列 $A_1, A_2, \dots$，$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$。

**由公理推出的常用性质**（考试直接可用）：

- $P(\varnothing) = 0$
- $P(\bar A) = 1 - P(A)$
- 加法公式：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$（减一次交集，因为加了两遍）
- 容斥推广：$P(A \cup B \cup C) = P(A)+P(B)+P(C) - P(AB)-P(AC)-P(BC) + P(ABC)$

**例（加法公式）**：某班 30% 喜欢篮球、40% 喜欢足球、15% 两者都喜欢。随机抽一人至少喜欢一种球类：

$$P = 0.3 + 0.4 - 0.15 = 0.55$$

## 1.4 条件概率、全概率公式与贝叶斯公式

### 1.4.1 条件概率：已知部分信息后重新评估

**定义**：已知事件 B 发生的前提下，A 发生的概率：

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \qquad P(B) > 0$$

**直觉（样本空间收缩）**：一旦知道 B 发生了，样本空间就从 $\Omega$ 缩小到 $B$；A 在新样本空间里的概率 =「A 且 B 占 $\Omega$ 的比例」除以「B 占 $\Omega$ 的比例」。

**例（扑克牌）**：从一副 52 张牌中抽一张。已知抽到的是红色牌，问它是红桃的概率。

$B$=红色（26 张），$A$=红桃（13 张）。$A \cap B = A$：

$$P(A \mid B) = \frac{13/52}{26/52} = \frac{13}{26} = \frac{1}{2}$$

直接想也对：红色牌里恰好一半是红桃。

**乘法公式**（由定义变形）：

$$P(A \cap B) = P(A \mid B)\, P(B) = P(B \mid A)\, P(A)$$

**例（不放回抽样）**：袋中 5 红 3 白，不放回连取两球，两次都红的概率：

$$P = \frac{5}{8} \times \frac{4}{7} = \frac{20}{56} \approx 0.357$$

> 第二球取红的概率是 $4/7$ 而不是 $4/8$：因为第一球已经拿走一个红球，样本空间收缩了。

### 1.4.2 全概率公式：由因求果

**划分（完备事件组）**：$B_1, \dots, B_n$ 两两互斥且并集为 $\Omega$。最常见的划分是 $B$ 与 $\bar B$。

**公式**：

$$P(A) = \sum_{i=1}^{n} P(A \mid B_i)\, P(B_i)$$

**推导（理解比背重要）**：因为 $B_i$ 互斥且覆盖全空间，事件 A 可分解为：

$$A = (A \cap B_1) \cup (A \cap B_2) \cup \cdots \cup (A \cap B_n)$$

右边各项互斥，概率相加：$P(A) = \sum_i P(A \cap B_i)$；再用乘法公式：$P(A \cap B_i) = P(A \mid B_i)P(B_i)$。证毕。

**例（工厂生产线）**：甲车间生产 60% 的产品，次品率 2%；乙车间生产 40%，次品率 5%。随机抽查一件，求它是次品的概率。

$$P(次) = 0.02 \times 0.6 + 0.05 \times 0.4 = 0.012 + 0.020 = 0.032 = 3.2\%$$

**直觉**：次品 = 「来自甲且次品」+「来自乙且次品」两条路径概率相加。

### 1.4.3 贝叶斯公式：由果溯因

**问题**：结果 A 已经发生，它更可能来自哪个原因 $B_i$？

$$P(B_i \mid A) = \frac{P(A \mid B_i)\, P(B_i)}{\sum_{j=1}^{n} P(A \mid B_j)\, P(B_j)}$$

**推导（只用两步，全在前面学过）**：

$$P(B_i \mid A) = \frac{P(A \cap B_i)}{P(A)} = \frac{P(A \mid B_i)\, P(B_i)}{\sum_j P(A \mid B_j)\, P(B_j)}$$

分子用乘法公式，分母用全概率公式。所以贝叶斯公式**不是新公理**，而是前三个公式的直接推论。

**三个名词**（务必记住）：

| 名称 | 含义 | 记号 |
|---|---|---|
| 先验 | 看到结果前对原因 $B_i$ 的信念 | $P(B_i)$ |
| 似然 | 若原因 $B_i$ 为真，观察到 A 的可能性 | $P(A \mid B_i)$ |
| 后验 | 看到结果后修正的信念 | $P(B_i \mid A)$ |

核心关系：**后验 ∝ 似然 × 先验**，分母只负责归一化（保证各后验之和为 1）。

**例 1（医学检测，经典中的经典）**：某种病患病率 1%，检测灵敏度（患者测出阳性）95%，假阳性率（健康人误报阳性）5%。问：测出阳性，真正患病的概率？

$$P(D \mid +) = \frac{0.95 \times 0.01}{0.95 \times 0.01 + 0.05 \times 0.99} = \frac{0.0095}{0.0095 + 0.0495} = \frac{0.0095}{0.059} \approx 0.161$$

**为什么只有 16%？** 用全概率拆解阳性人群：

- 真患病且阳性：$1\% \times 95\% = 0.95\%$
- 健康却误报：$99\% \times 5\% = 4.95\%$

100 个阳性里约 5 个是误报、不到 1 个是真患者——**假阳性在数量上淹没了真阳性**。先验（患病率）太低，再准的检测也救不回来。这就是为什么阳性结果需要二次确认（复查后先验变成 16%，再测一次阳性后验约 78%）。

> **数科直觉（混淆矩阵版）**：把「阳性」换成「模型预测为正」，把「患病」换成「真实为正」：
> - 灵敏度 $P(+\mid D)$ = 真正例率 TPR（recall）
> - 假阳性率 $P(+\mid \bar D)$ = 1 − 特异度
> - 后验 $P(D \mid +)$ = **精确率 precision**！
> - 患病率 = **base rate（先验）**
>
> 一个模型 recall=95%、特异度 95% 看似很好，但如果正类只占 1%，**precision 也只有约 16%**——「预测为正」的人里 84% 是误报。这是风控、医疗 AI、异常检测里被反复踩的坑：**只看 recall/accuracy 不看 base rate 是自欺欺人。**

**例 2（垃圾邮件过滤，朴素贝叶斯雏形）**：

设事件 S=「是垃圾邮件」，词 W=「邮件中包含『中奖』」。已知：垃圾邮件率 $P(S)=0.2$；垃圾邮件含该词 $P(W\mid S)=0.9$；正常邮件含该词 $P(W\mid \bar S)=0.1$。问：含「中奖」的邮件是垃圾的概率？

$$P(S \mid W) = \frac{0.9 \times 0.2}{0.9 \times 0.2 + 0.1 \times 0.8} = \frac{0.18}{0.26} \approx 0.692$$

直觉：虽然 10% 的正常邮件也含这个词，但垃圾邮件中这个词出现更频繁，加上垃圾邮件本身占 20%，含词邮件 7 成是垃圾。

> **延伸**：真正的朴素贝叶斯分类器（第 2 章和第 6 章会细讲）把一封邮件拆成很多词，假设各词**条件独立**（在给定类别下），然后用贝叶斯公式把「多词联合似然」乘起来。条件独立假设是「朴素」的由来——虽然现实中词并不独立，但效果依然惊人地好，是邮件过滤、情感分析的基础模型。

### 1.4.4 独立性

**定义**：事件 A 与 B 独立 ⇔

$$P(A \cap B) = P(A)\, P(B)$$

等价地（当 $P(B)>0$）：$P(A \mid B) = P(A)$——**知道 B 发生不改变 A 的概率**。

**例（两次抛硬币）**：A=「第一次正面」，B=「第二次正面」。$P(A \cap B)=1/4 = P(A)P(B)$，独立。

**常见陷阱：互斥 ≠ 独立**。

若 A、B 互斥（$A \cap B = \varnothing$）且 $P(A), P(B) > 0$，则 $P(A \cap B) = 0 \ne P(A)P(B) > 0$——**互斥事件必然不独立**！

直觉：互斥意味着「知道 A 发生，B 就 100% 不发生」，信息量极大，怎么可能独立？

**例**：掷骰子，A=「偶数」，B=「大于 4」。$P(A \cap B) = P(\{6\}) = 1/6$，而 $P(A)P(B) = \frac{3}{6} \times \frac{2}{6} = \frac{1}{6}$。碰巧相等，独立。换个例子：A=「偶数」，B=「大于 5」：$P(A \cap B)=P(\{6\})=1/6$，$P(A)P(B)=\frac{3}{6}\times\frac{1}{6}=\frac{1}{12}$，不独立——知道掷出大于 5 后，「偶数」的概率从 $1/2$ 变成 1。

**多事件独立**：$A_1, \dots, A_n$ 相互独立，要求**任意**子集的交的概率等于各自概率的乘积（不只是两两独立）。

## 1.5 伯努利概型

**伯努利试验**：只有两个结果（成功/失败）的试验，成功概率 $p$。

**n 重伯努利试验**：独立重复 n 次，求成功 k 次的概率：

$$P(\text{恰好 } k \text{ 次成功}) = \binom{n}{k}\, p^k (1-p)^{n-k}$$

推导：某一种「k 次成功、n−k 次失败」的具体顺序概率为 $p^k(1-p)^{n-k}$，而这样的顺序共有 $\binom{n}{k}$ 种，且互斥，相加即得。

**例（质检）**：某产品次品率 5%，抽检 5 件，求恰好 2 件次品的概率：

$$\binom{5}{2} (0.05)^2 (0.95)^3 = 10 \times 0.0025 \times 0.8574 \approx 0.0214$$

**例（有放回抽样）**：10 道选择题（4 选 1），全蒙对 6 道及以上的概率（$p=0.25$）：

$$\sum_{k=6}^{10} \binom{10}{k} (0.25)^k (0.75)^{10-k} \approx 0.0197$$

> 这正是第 2 章**二项分布**的由来，也是第 4 章大数定律的舞台：$k/n \to p$（频率趋稳）。

## 1.6 数据科学视角：本章知识怎么用

### 1.6.1 用随机模拟「验证」概率

概率论给理论答案，模拟给数值验证——两者互证。

**模拟抛硬币（频率 → 概率）**：

```python
import numpy as np
rng = np.random.default_rng(42)
for n in [10, 100, 10000, 100000]:
    heads = (rng.random(n) < 0.5).sum()
    print(n, heads / n)
```

你会看到频率从 0.6 之类飘忽的值，慢慢稳定到 0.5 附近——这就是大数定律（第 4 章）的直观。

**模拟生日问题**：

```python
import numpy as np
rng = np.random.default_rng(0)
def prob_dup(n_people, trials=100000):
    dup = 0
    for _ in range(trials):
        bdays = rng.integers(0, 365, size=n_people)
        dup += len(set(bdays)) < n_people
    return dup / trials
print(prob_dup(23))   # ≈ 0.51
print(prob_dup(50))   # ≈ 0.97
```

理论值 0.507 / 0.97 与模拟吻合——这是「先理论后验证」的标准工作流。

### 1.6.2 朴素贝叶斯分类器

前面垃圾邮件例子的规模化版本：给定特征向量 $x=(x_1,\dots,x_d)$（如词是否出现），在**条件独立假设**下：

$$P(S \mid x) \propto P(S) \prod_{i=1}^{d} P(x_i \mid S)$$

- 先验 $P(S)$：垃圾邮件占比；
- 似然 $P(x_i \mid S)$：垃圾邮件中出现词 $i$ 的比例（拉普拉斯平滑处理零概率）；
- 决策：$P(S \mid x) > 0.5$ 判为垃圾。

这是 sklearn 的 `MultinomialNB` 的原理，也解释了为什么需要**平滑**：某个词训练集没见过，$P=0$ 会一刀切抹掉其他证据（$0 \times$ 任何数都是 0）。

### 1.6.3 混淆矩阵就是一张「条件概率表」

|  | 真实=正 | 真实=负 |
|---|---|---|
| 预测=正 | TP | FP |
| 预测=负 | FN | TN |

- 灵敏度/recall：$P(\text{预测正} \mid \text{真实正}) = TP/(TP+FN)$
- 特异度：$P(\text{预测负} \mid \text{真实负}) = TN/(TN+FP)$
- **精确率/precision：$P(\text{真实正} \mid \text{预测正}) = TP/(TP+FP)$——这就是后验！**

「模型准确率 95%」在正类占比 1% 时毫无意义——你需要用贝叶斯公式看 precision。

### 1.6.4 贝叶斯更新（迭代思维）

上一次的后验 = 下一次的先验。例：

1. 先验 $P(D)=1\%$，一次阳性 → 后验 16%；
2. 把 16% 当作新先验，再做一次独立检测（灵敏度 95%、假阳性 5%）：

$$P(D \mid +) = \frac{0.95 \times 0.16}{0.95 \times 0.16 + 0.05 \times 0.84} \approx 0.78$$

两次独立阳性后，患病概率从 1% 升到 78%。**证据重复叠加，信念指数式增强**——这是贝叶斯推断（第 6、9 章）的核心直觉。

## 1.7 常见误区

1. **把 $P(A \mid B)$ 当 $P(B \mid A)$**。检测灵敏度高 ≠ 阳性即患病（见 1.4.3）。
2. **互斥当独立**。互斥（且概率非零）必然不独立；两者是相反方向的「信息」关系。
3. **忘记样本空间收缩**。不放回抽样的第二次概率分母是 $n-1$ 不是 $n$。
4. **古典概型忘记有序性**。两颗骰子 (1,6) 与 (6,1) 是两个样本点。
5. **把 $P(A)=0$ 当「不可能」**。连续型随机变量单点概率为 0 但事件可能发生（第 2 章详述）。
6. **只报灵敏度/准确率不报 base rate**。在正类极少的场景，准确率是误导性指标。

## 1.8 练习（附参考答案）

**1. 一个盒子有 4 红 6 蓝，随机取两个（不放回）。**
(a) 两个都红的概率？(b) 一红一蓝的概率？

(a) $\dfrac{4}{10} \times \dfrac{3}{9} = \dfrac{2}{15}$。(b) $\dfrac{4}{10}\times\dfrac{6}{9} + \dfrac{6}{10}\times\dfrac{4}{9} = \dfrac{8}{15}$（红先蓝后 + 蓝先红后）。

**2. 两事件 $P(A)=0.4$，$P(B)=0.3$，$P(A \cup B)=0.6$。求 $P(A \cap B)$、$P(A \mid B)$。**

$P(A\cap B) = 0.4+0.3-0.6 = 0.1$；$P(A\mid B) = 0.1/0.3 = 1/3$。

**3. 某工厂三台机器：A 生产 50%（次品率 3%），B 生产 30%（次品率 4%），C 生产 20%（次品率 5%）。抽到一件次品，问它来自 A 的概率？**

全概率分母：$0.03\times0.5 + 0.04\times0.3 + 0.05\times0.2 = 0.015+0.012+0.010 = 0.037$。

$P(A\mid 次) = 0.015/0.037 \approx 0.405$。

**4. 掷一颗骰子两次，求「点数之和为 9」与「第一次为偶数」是否独立？**

和为 9 的样本点：$(3,6),(4,5),(5,4),(6,3)$ 共 4 个，$P=4/36=1/9$。第一次偶数的概率 $1/2$。交集：$(4,5),(6,3)$ 共 2 个，$P=2/36=1/18$。

$\frac{1}{9}\times\frac12 = \frac{1}{18}$ = 交集概率，**独立**。

**5.（贝叶斯应用题）某疾病检测：患病率 0.5%，灵敏度 99%，假阳性率 2%。一个人检测阳性，真患病的概率？**

$P(D\mid+) = \dfrac{0.99\times0.005}{0.99\times0.005 + 0.02\times0.995} = \dfrac{0.00495}{0.00495+0.0199} \approx 0.199$。约 20%。

**6.（数科向）一个模型的混淆矩阵：TP=90，FP=10，FN=200，TN=700。求 precision、recall、base rate、以及随机猜测的准确率。**

precision $=90/100=0.9$；recall $=90/290≈0.31$；base rate $=290/1000=0.29$；随机猜的准确率取决于猜的策略，若全猜负则准确率 $=0.71$——比模型「总体准确率」还高，说明准确率在此场景无意义。

## 1.9 本章公式表与小结

### 核心公式表

| 内容     | 公式                                                                     |     |     |        |     |
| ------ | ---------------------------------------------------------------------- | --- | --- | ------ | --- |
| 古典概型   | $P(A) = \dfrac{                                                        | A   | }{  | \Omega | }$  |
| 加法公式   | $P(A \cup B) = P(A)+P(B)-P(A\cap B)$                                   |     |     |        |     |
| 条件概率   | $P(A\mid B) = \dfrac{P(A\cap B)}{P(B)}$                                |     |     |        |     |
| 乘法公式   | $P(A\cap B) = P(A\mid B)P(B)$                                          |     |     |        |     |
| 全概率    | $P(A) = \sum_i P(A\mid B_i)P(B_i)$                                     |     |     |        |     |
| 贝叶斯    | $P(B_i\mid A) = \dfrac{P(A\mid B_i)P(B_i)}{\sum_j P(A\mid B_j)P(B_j)}$ |     |     |        |     |
| 独立     | $P(A\cap B) = P(A)P(B)$                                                |     |     |        |     |
| n 重伯努利 | $P(k\text{ 次成功}) = \binom{n}{k}p^k(1-p)^{n-k}$                         |     |     |        |     |

### 知识脉络

```
随机试验 → 样本空间 Ω → 事件（Ω 的子集）
    │                │
    ▼                ▼
 概率公理         事件运算（并交集补、德摩根律）
    │                │
    └──────┬─────────┘
           ▼
   条件概率 P(A|B) ──→ 独立性
       │
       ├── 乘法公式
       ├── 全概率公式（由因求果）
       └── 贝叶斯公式（由果溯因，后验 ∝ 似然×先验）
           └── 应用：朴素贝叶斯、precision、贝叶斯更新
```

**一句话总结**：本章建立「不确定性」的精确语言——用集合描述事件、用公理定义概率、用条件概率做信息更新；而贝叶斯公式是其中最锋利的一把刀，它把「看到数据之前」变成「看到数据之后」。
