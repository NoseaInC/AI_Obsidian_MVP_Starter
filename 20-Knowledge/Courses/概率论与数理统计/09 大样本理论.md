# 09 大样本理论（教材版）

> 学完本章你将能：理解一致性、渐近正态性的严格含义；掌握 Slutsky 定理及其「用 s 替代 σ」的应用；掌握单变量与多变量 Delta 方法，能算比率、乘积、logit 等复合指标的渐近方差；理解 MLE 的渐近性质与 Fisher 信息；区分 Wald、似然比、得分三种渐近检验。

## 学习目标

1. 区分一致性（收敛到真值）与渐近正态性（波动形状）；
2. 理解 Slutsky 定理并会用它证明「s 替代 σ」合法；
3. 掌握 Delta 方法的推导（一阶泰勒展开）；
4. 会用 Delta 方法算比率、logit、乘积的标准误；
5. 理解 MLE 的一致/渐近正态/渐近有效三性质；
6. 区分 Wald、LRT、得分检验。

---

## 9.0 引言：为什么需要大样本理论？

很多估计量没有精确的抽样分布：

- 比率 $\hat R = \bar{X}/\bar{Y}$（人均消费 = 总消费/人数）——分子分母都随机
- 转化率之差、点击率×转化率这类复合指标
- 中位数、分位数等非线性统计量

**大样本理论用「n 足够大时近似正态」解决这一切**：不需要精确分布，只要知道均值和（渐近）方差就能做推断。这是现代 A/B 测试指标分析、逻辑回归推断的理论基础。

---

## 9.1 一致性与渐近正态性

### 一致性

$\hat\theta_n \xrightarrow{P} \theta$：样本越大，估计越准（收敛到真值）。大数定律的化身。

### 渐近正态性

$$\sqrt{n}(\hat\theta_n - \theta) \xrightarrow{d} N(0, V)$$

「标准化后」的波动趋于正态，V 为渐近方差。CLT 是它的特例：

$$\sqrt{n}(\bar{X}_n-\mu) \xrightarrow{d} N(0,\sigma^2), \qquad V=\sigma^2$$

**两者的关系**：一致性保证「点估计不错」，渐近正态性给出「不确定性怎么分布」——做置信区间、检验都需要后者。

---

## 9.2 Slutsky 定理

### 定理

若 $X_n \xrightarrow{d} X$ 且 $a_n \xrightarrow{P} a$（常数），则：

$$X_n + a_n \xrightarrow{d} X + a, \qquad a_n X_n \xrightarrow{d} aX$$

**意义**：极限分布里的随机部分，可以用「收敛到常数的估计量」替换而不改变结论。

### 关键应用：用 s 替代 σ

样本标准差 $S_n \xrightarrow{P} \sigma$（一致性）。于是：

$$\frac{\sqrt{n}(\bar{X}_n-\mu)}{S_n} = \underbrace{\frac{\sqrt{n}(\bar{X}_n-\mu)}{\sigma}}_{\xrightarrow{d} N(0,1)} \cdot \underbrace{\frac{\sigma}{S_n}}_{\xrightarrow{P} 1} \xrightarrow{d} N(0,1)$$

**所以大样本下不知道 σ 也没关系**——Z 检验里用 s 替代 σ 完全合法。

**🎯 面试考点——「为什么 t 检验和 Z 检验大样本下等价？」**：t 统计量分母 $S/\sqrt{n}$，由 Slutsky，$S \xrightarrow{P} \sigma$，所以 $t_n \to N(0,1)$。这和第 5 章「t 分布 n→∞ 趋于正态」互相印证。

## 9.3 Delta 方法

### 问题

已知 $\sqrt{n}(\hat\theta_n-\theta) \xrightarrow{d} N(0,V)$，想知道 $g(\hat\theta_n)$ 的渐近分布。

### 单变量 Delta 方法（推导）

对 $g$ 在 $\theta$ 处一阶泰勒展开：

$$g(\hat\theta_n) \approx g(\theta) + g'(\theta)(\hat\theta_n - \theta)$$

两边减 $g(\theta)$ 乘 $\sqrt{n}$：

$$\sqrt{n}\bigl(g(\hat\theta_n)-g(\theta)\bigr) \approx g'(\theta)\,\sqrt{n}(\hat\theta_n-\theta) \xrightarrow{d} N(0,\ g'(\theta)^2 V)$$

**结论**：方差被斜率平方放大——`Var(g(θ̂)) ≈ g'(θ)²·Var(θ̂)`。

### 例 1：比率估计

$\hat R = \bar{X}/\bar{Y}$（人均消费）。$g(x,y)=x/y$，$\nabla g = (1/y,\ -x/y^2)$，由多变量 Delta 方法：

$$\mathrm{Var}(\hat R) \approx \frac{\mathrm{Var}(X)}{\mu_Y^2} + \frac{\mu_X^2\,\mathrm{Var}(Y)}{\mu_Y^4} - 2\frac{\mu_X\,\mathrm{Cov}(X,Y)}{\mu_Y^3}$$

**💼 工作实战**：ARPU（每用户收入）= 总收入/总用户数。直接给 ARPU 的 CI 而不只是点估计——用 Delta 方法算标准误，或直接用 Bootstrap（第 5 章）。这是 AB 测试复合指标分析的标准做法。

### 例 2：logit / log 变换

$\hat p$ 成功概率，$\sqrt{n}(\hat p-p)\to N(0,\ p(1-p))$。

- **logit** $g(p)=\ln\frac{p}{1-p}$：$g'(p)=\frac{1}{p(1-p)}$，$\mathrm{Var}(g(\hat p))\approx\frac{p(1-p)}{n}\cdot\frac{1}{p^2(1-p)^2}=\frac{1}{np(1-p)}$——逻辑回归系数标准误的来源。
- **log** $g(p)=\ln p$：$\mathrm{Var}(\ln\hat p)\approx\frac{1-p}{np}$——比率类指标常用 log 变换构造区间，因为 log 变换后更接近正态且下限不会为负。

**🎯 面试考点——「为什么要做 log 变换？」**：两个作用：① 让右偏分布更接近正态（CLT 更快生效）；② 乘法关系变加法（系数可解释为百分比变化）。代价：变换后解释要回代。

### 多变量 Delta 方法

$$\sqrt{n}\bigl(g(\hat\theta_n)-g(\theta)\bigr) \xrightarrow{d} N\bigl(0,\ (\nabla g)^T \Sigma (\nabla g)\bigr)$$

**例**：同时估计点击率与转化率，求复合指标「点击率 × 转化率」的方差——用梯度传播协方差。

## 9.4 MLE 的渐近性质

正则条件下，MLE $\hat\theta_{MLE}$：

1. **一致性**：$\hat\theta \xrightarrow{P} \theta$
2. **渐近正态性**：$\sqrt{n}(\hat\theta-\theta) \xrightarrow{d} N(0,\ I(\theta)^{-1})$，$I(\theta)$ 为 Fisher 信息
3. **渐近有效性**：达到 CR 下界，是所有一致估计量中渐近方差最小的

### Fisher 信息

$$I(\theta) = -\mathbb{E}\left[\frac{\partial^2}{\partial\theta^2}\ln f(X;\theta)\right]$$

**直觉**：似然曲面在真值处的「弯曲程度」——越弯，数据对参数越敏感，估计越准。

**例（二项）**：$I(p)=\frac{n}{p(1-p)}$，渐近方差 $=\frac{p(1-p)}{n}$，与 CLT 直接算一致——$\hat p$ 是有效估计。

**🎯 面试考点——「Fisher 信息大意味着什么？」**：信息越大，参数能被估计得越准（方差下界越小）。直观：似然函数对参数越「敏感」（尖），数据里关于参数的信息越多。

## 9.5 Wald 检验、似然比检验、得分检验

三者都是「检验 $H_0: \theta=\theta_0$」的大样本方法，渐近等价（n→∞ 时功效相同）：

| 检验 | 思想 | 统计量 |
|---|---|---|
| **Wald** | 看估计值离 $\theta_0$ 多远 | $W = \frac{(\hat\theta-\theta_0)^2}{\widehat{\mathrm{Var}}(\hat\theta)} \xrightarrow{d} \chi^2_1$ |
| **似然比（LRT）** | 看受限与不受限似然差多少 | $-2\ln\Lambda = -2\ln\frac{\sup_{\Theta_0}L}{\sup_{\Theta}L} \xrightarrow{d} \chi^2_1$ |
| **得分（Score）** | 看 $\theta_0$ 处似然导数多大 | $S = \frac{\ell'(\theta_0)^2}{nI(\theta_0)} \xrightarrow{d} \chi^2_1$ |

**直觉**：
- Wald：估计已经出来了，看它离假设多远（最常用，统计软件默认）
- LRT：比较两个模型的似然，适合嵌套模型比较（如加不加一个特征）
- Score：还没估计，只看 $\theta_0$ 处的斜率是否「应该爬」

**💼 工作实战——特征筛选**：逻辑回归加一个特征后，比较含/不含该特征的模型：

```python
import statsmodels.api as sm
m0 = sm.Logit(y, X0).fit(disp=0)   # 不含特征
m1 = sm.Logit(y, X1).fit(disp=0)   # 含特征
lr = 2*(m1.llf - m0.llf)           # 似然比统计量
p_val = 1 - stats.chi2.cdf(lr, 1)
```

## 💼 工作实战：A/B 测试的复合指标

### 场景

实验组/对照组各 10000 人，总 GMV 和人数都随机：

```python
import numpy as np
n = 10000
x = np.random.gamma(2, 40, n)   # 实验组人均消费
# ARPU 的 Bootstrap CI（避免手推 Delta 公式）
bs = [np.random.choice(x, n, replace=True).mean() for _ in range(10000)]
ci = np.percentile(bs, [2.5, 97.5])
```

### 什么时候手推、什么时候 Bootstrap

- 解析分布难求、公式复杂 → Bootstrap（计算便宜，假设少）
- 需要部署/审计、公式要写进文档 → Delta 方法（可复现、可解释）
- 两者大样本下结论一致，选哪个取决于工程与沟通需求

## 🎯 面试高频考点速览

1. **一致性和渐近正态性的区别？** 前者收敛到真值（点），后者波动趋于正态（分布）。
2. **Slutsky 定理干什么用？** 用收敛到常数的估计量替换极限分布中的常数（s→σ）。
3. **Delta 方法怎么来的？** 一阶泰勒展开：$g(\hat\theta)\approx g(\theta)+g'(\theta)(\hat\theta-\theta)$。
4. **比率的标准误怎么算？** Delta 方法（或 Bootstrap）。
5. **log 变换有什么用？** 正态化 + 乘法变加法。
6. **MLE 三个渐近性质？** 一致、渐近正态（方差 $I^{-1}$）、渐近有效。
7. **Wald/LRT/Score 区别？** 估计值距离 / 似然比 / 得分斜率；渐近等价。

## 练习（含解答）

**练 1**：$\hat p$ 来自 $B(n,p)$，用 Delta 方法求 $\ln\hat p$ 的渐近方差。

解：$g'(p)=1/p$，$\mathrm{Var}(\ln\hat p)\approx g'(p)^2\cdot\frac{p(1-p)}{n}=\frac{1-p}{np}$。

**练 2**：$\bar{X}$ 与 $\bar{Y}$ 独立，$\mu_X=10,\ \sigma_X=2,\ \mu_Y=5,\ \sigma_Y=1$，$n=100$。求 $\hat R=\bar{X}/\bar{Y}$ 的渐近标准差。

解：$\mathrm{Var}\approx\frac{4}{25}+\frac{100\times1}{625}=\frac{4}{25}+\frac{4}{25}=\frac{8}{25}$，$\mathrm{SD}\approx\sqrt{8/25}/\sqrt{100}\approx0.0566$（注意分母是 $\sqrt{n}$ 缩放）。

**练 3（面试）**：为什么说「大样本下 t 检验 ≈ Z 检验」？

解：$S\xrightarrow{P}\sigma$，由 Slutsky 分母替换后仍收敛 $N(0,1)$；等价地 $t_n\to N(0,1)$。

**练 4**：用 Delta 方法给出 $g(\theta)=\theta^2$ 在 $\hat\theta$ 处的渐近方差表达式。

解：$g'(\theta)=2\theta$，$\mathrm{Var}(g(\hat\theta))\approx4\theta^2\,\mathrm{Var}(\hat\theta)$。

**练 5（概念）**：Wald 与 LRT 什么时候结论会不同？

解：渐近等价（大样本）但有限样本可能不同；Wald 依赖参数化的「平方距离」，LRT 对参数化不变（更稳健）。非正态或小样本时优先 LRT。
