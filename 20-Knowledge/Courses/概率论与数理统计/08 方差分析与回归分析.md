# 08 方差分析与回归分析（教材版）

> 学完本章你将能：理解 ANOVA 的平方和分解思想与 F 检验；知道为什么不能直接用多个 t 检验代替 ANOVA；掌握一元线性回归的最小二乘估计、系数检验与区间估计；区分置信区间与预测区间；用残差图做回归诊断；理解回归系数 ≠ 因果效应（混淆变量问题）——这是数据科学里最容易踩的坑。

## 学习目标

1. 理解 ANOVA 的平方和分解（总 = 组间 + 组内）与 F 统计量；
2. 理解多重比较的必要性与 Bonferroni/Tukey；
3. 掌握 OLS 估计公式与推导（最小化残差平方和）；
4. 掌握回归系数的 t 检验与置信区间；
5. 区分预测区间与置信区间并理解其差异来源；
6. 会用残差图、QQ 图、R² 做诊断；
7. 深刻理解混淆变量与「回归 ≠ 因果」。

---

## 8.0 引言：两组不够用了

第 7 章会比较两个均值（t 检验）。但现实常有多组或连续自变量：

- 三种定价策略，哪个销量高？→ ANOVA
- 广告费多少，销量多少？→ 回归

**ANOVA 回答「分组有没有影响」，回归回答「X 每变一点 Y 平均变多少」**——两者本质都是「用方差分解 + F/t 检验判断关系是否显著」。

---

## 8.1 单因素方差分析（ANOVA）

### 问题与动机

比较 k 组均值是否相同（三种肥料产量、四种版本转化率）。

**为什么不用 $\binom{k}{2}$ 个两两 t 检验？** 多重检验会让第一类错误累积：k=3 时做 3 次检验，若各次独立，整体 α ≈ $1-(1-0.05)^3 \approx 14\%$，远超名义 5%。

### 平方和分解（核心思想）

$$\underbrace{SS_{总}}_{\text{所有数据对总均值的波动}} = \underbrace{SS_{组间}}_{\text{各组均值之间的差异}} + \underbrace{SS_{组内}}_{\text{各组内部的随机波动}}$$

直觉：总差异可以拆成「组与组之间的差异」+「组内个体差异」。如果组间差异远大于组内噪声，说明分组真的有影响。

### F 统计量

$$F = \frac{SS_{组间}/(k-1)}{SS_{组内}/(n-k)} \sim F_{k-1,\ n-k}$$

分子是「组间均方」（解释掉的变异），分母是「组内均方」（噪声）。F 大 → 组间效应显著。

**例（三种肥料）**：每组 10 块地，$SS_{组间}=120$，$SS_{组内}=270$：

$$F = \frac{120/2}{270/27} = 6.0, \qquad F_{2,27,0.05} \approx 3.35$$

6 > 3.35 → 拒绝「三组产量相同」——肥料有效应。

---

## 8.2 多重比较

ANOVA 只回答「有没有差异」，不回答「哪两组不同」。多重比较在**控制整体错误率**的前提下两两比较：

- **Bonferroni**：每对比较用 α/比较次数。简单、保守（组数多时功效低）。
- **Tukey HSD**：用学生化极差分布，专门为「所有两两比较」设计，功效更好。

**💼 工作实战**：四组 A/B/C/D 定价，ANOVA 显著后：

```python
from statsmodels.stats.multicomp import pairwise_tukeyhsd
res = pairwise_tukeyhsd(sales, group, alpha=0.05)
print(res.summary())  # 输出两两比较的显著性矩阵
```

## 8.3 一元线性回归与最小二乘估计

### 模型

$$Y = \beta_0 + \beta_1 X + \varepsilon$$

假设：误差 $\varepsilon$ 独立、$\mathbb{E}[\varepsilon]=0$、$\mathrm{Var}(\varepsilon)=\sigma^2$ 恒定、正态（做检验时需要）。

### OLS 推导

最小化 $Q = \sum_{i=1}^n (Y_i - \beta_0 - \beta_1 X_i)^2$。对 $\beta_0$、$\beta_1$ 求偏导置零：

$$\frac{\partial Q}{\partial \beta_1} = -2\sum X_i(Y_i-\beta_0-\beta_1 X_i) = 0$$

解得：

$$\hat\beta_1 = \frac{\sum (X_i-\bar{X})(Y_i-\bar{Y})}{\sum (X_i-\bar{X})^2} = \frac{\mathrm{Cov}(X,Y)}{\mathrm{Var}(X)}, \qquad \hat\beta_0 = \bar{Y} - \hat\beta_1\bar{X}$$

**直觉**：斜率 = 协方差/方差——X 与 Y 共变的强度，除以 X 自身的波动归一化。

**例（广告 vs 销量）**：$\hat\beta_1 = 1.8$：每多投 1 万元广告，销量平均多 1.8 万件。**单位很重要**：X 用「万元」时系数是 1.8；改用「元」系数变 0.0018。

---

## 8.4 回归系数的区间估计与显著性检验

误差正态时：

$$\frac{\hat\beta_1 - \beta_1}{\mathrm{SE}(\hat\beta_1)} \sim t_{n-2}$$

- 检验 $H_0: \beta_1=0$：斜率不为 0 ⇔ X 与 Y 有**线性**关系
- 置信区间：$\hat\beta_1 \pm t_{n-2,\alpha/2}\,\mathrm{SE}(\hat\beta_1)$

**例**：$\hat\beta_1 = 1.8$，$\mathrm{SE}=0.5$，$n=30$：

$$t = \frac{1.8}{0.5} = 3.6, \qquad t_{28,0.025} \approx 2.05$$

$3.6 > 2.05$ → 拒绝 $\beta_1=0$，广告费与销量显著相关。95% CI：$1.8 \pm 2.05\times0.5 = [0.775,\ 2.825]$。

---

## 8.5 预测区间与置信区间

对给定 $X=x_0$ 预测 $Y$：

- **置信区间（回归线的位置）**：$\hat y_0 \pm t\, s\sqrt{\frac{1}{n}+\frac{(x_0-\bar{x})^2}{\sum(x_i-\bar{x})^2}}$
- **预测区间（新个体）**：$\hat y_0 \pm t\, s\sqrt{1+\frac{1}{n}+\frac{(x_0-\bar{x})^2}{\sum(x_i-\bar{x})^2}}$

**关键区别**：预测区间比置信区间宽（多了「+1」）——因为新个体 Y 本身带随机波动 $\varepsilon$，而回归线位置的置信区间只含估计不确定性。

**直觉**：越远离 $\bar{x}$，区间越宽（估计回归线在远端越不确定）。

**🎯 面试考点——「置信区间和预测区间有什么区别？」**：置信区间是关于「平均响应 $\mathbb{E}[Y\mid X]$」的区间（只含估计误差）；预测区间是关于「一个新观测 Y」的区间（估计误差 + 个体随机波动）。预测区间必然更宽。

---

## 8.6 回归诊断与模型假设

### 基本假设（LINE）

1. **L**inear：关系是线性的
2. **I**ndependent：误差相互独立
3. **N**ormal：误差正态（检验/区间需要）
4. **E**qual variance：误差方差恒定（同方差）

### 诊断工具

| 工具 | 看什么 | 异常信号 |
|---|---|---|
| 残差 vs 拟合值图 | 无结构随机散布 | 漏斗形（异方差）、曲线（非线性） |
| QQ 图 | 残差是否正态 | 两端偏离直线（厚尾/偏态） |
| R² | 拟合优度 | 过低说明模型解释力差 |

```python
import statsmodels.api as sm
model = sm.OLS(y, sm.add_constant(x)).fit()
resid = model.resid
print(model.summary())        # 系数、SE、p 值、R²
sm.qqplot(resid, line='s')    # 正态性诊断
```

**⚠️ 异方差（漏斗形残差）怎么办？** 对数变换 Y、加权最小二乘、或用稳健标准误（HC 标准误）。

## ⚠️ 8.7 回归 ≠ 因果：混淆变量（重中之重）

**例（冰淇淋与溺水）**：冰淇淋销量 X 回归溺水人数 Y，斜率显著为正。但真正驱动两者的是温度 Z——遗漏 Z 造成虚假相关。加入温度后，冰淇淋系数可能不再显著甚至变号（辛普森悖论的一种表现）。

**为什么观测数据会骗人**：

- 混淆变量同时影响 X 与 Y（温度→冰淇淋、温度→游泳→溺水）
- 观测数据中 X 的分配不由我们控制，混杂无法被随机化消除
- 回归系数只捕捉「控制其他变量后的相关」，不等于因果效应

**判断因果需要**：随机化实验（A/B 测试）、或观测数据的因果推断方法（倾向得分匹配、工具变量、双重稳健估计）。

> 延伸：观测数据如何估计因果效应，见 [[观测数据中的平均处理效应估计]]。

**🎯 面试考点——「回归系数显著说明 X 导致 Y 吗？」**：不。只能说明「控制模型内变量后，X 与 Y 相关」。遗漏变量、反向因果、选择偏差都可能导致显著但非因果。经典例子：鞋码与阅读能力正相关（年龄是混淆变量）。

## 💼 工作实战：回归建模全流程

### 1. 探索（EDA）

散点图看线性性、相关矩阵看共线性（|ρ|>0.8 提示多重共线性 → VIF 诊断）。

### 2. 建模与解释

```python
import statsmodels.api as sm
X = sm.add_constant(df[['ad_spend','seasonal']])  # 加截距
model = sm.OLS(df['sales'], X).fit()
print(model.summary())  # 系数、p 值、R²、F 检验
```

解读输出：`coef`（斜率）、`P>|t|`（系数显著性）、`R-squared`、`F-statistic`（整体显著性）。

### 3. 诊断与迭代

残差图、QQ 图；异常点（高杠杆、大残差）；必要时做特征变换、加交互项。

### 4. 业务解读（单位 + 区间 + 因果提醒）

汇报：

- 效应量：每增加 1 单位 X，Y 平均变化 $\hat\beta_1$（带 95% CI）
- 显著性：p 值
- 局限：观测数据 → 相关而非因果，可能有混淆变量

## 🎯 面试高频考点速览

1. **ANOVA 为什么不用多个 t 检验？** 多重比较累积第一类错误。
2. **F 统计量直觉？** 组间均方/组内均方；大于临界值 → 组间差异显著。
3. **OLS 斜率 = ？** $\mathrm{Cov}(X,Y)/\mathrm{Var}(X)$。
4. **预测区间 vs 置信区间？** 预测区间含个体波动，更宽。
5. **残差图看什么？** 漏斗 = 异方差；曲线 = 非线性；无结构 = 好。
6. **回归显著 = 因果？** 不；混淆变量、遗漏变量、反向因果都是威胁。
7. **多重共线性危害？** 系数不稳定、SE 膨胀、单个系数不可解释。

## 练习（含解答）

**练 1**：三组数据：$SS_{组间}=60$，$SS_{组内}=90$，每组 n=10。检验三组均值是否相同（α=0.05）。

解：$F=\frac{60/2}{90/27}=9$，$F_{2,27,0.05}\approx3.35$，9>3.35 → 拒绝，组间差异显著。

**练 2**：$n=20$，$\hat\beta_1=2.5$，$\mathrm{SE}=1.0$。检验 $\beta_1=0$ 并给 95% CI。

解：$t=2.5$，$t_{18,0.025}\approx2.101$，$2.5>2.101$ → 拒绝。CI：$2.5\pm2.101\times1.0=[0.399,\ 4.601]$。

**练 3**：为什么预测区间比置信区间宽？给出「+1」的来源。

解：新观测 $Y_0 = \hat y_0 + (\text{估计误差}) + \varepsilon_0$，个体波动 $\varepsilon_0$ 方差 $\sigma^2$ 贡献了公式里的「1」；置信区间只有估计误差项。

**练 4（概念）**：散点图显示 X 增大时 Y 的离散度明显增大，违反哪个假设？怎么处理？

解：违反同方差（异方差）。处理：对数/Box-Cox 变换 Y、加权最小二乘、稳健标准误。

**练 5（面试）**：公司发现「购买保险的人寿命更长」，能否推出「买保险延长寿命」？

解：不能——健康人群更倾向买保险（选择偏差/混淆变量），相关不等于因果。
