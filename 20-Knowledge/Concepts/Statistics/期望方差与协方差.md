# 期望、方差与协方差

## 期望

### 定义
- **离散**：$E[X] = \sum_x x \cdot p_X(x)$
- **连续**：$E[X] = \int_{-\infty}^{\infty} x \cdot f_X(x)\,dx$

### 核心性质

| 性质 | 公式 |
|------|------|
| 线性 | $E[aX + bY] = aE[X] + bE[Y]$（无条件成立） |
| 函数期望（LOTUS） | $E[g(X)] = \int g(x) f_X(x)\,dx$ |
| 独立时乘积 | $E[XY] = E[X]E[Y]$（若 $X \perp Y$） |

### 条件期望

$E[Y \mid X=x]$ 是在 $X=x$ 条件下 $Y$ 的均值。**条件期望本身是随机变量**：$E[Y \mid X]$ 是 $X$ 的函数。

**重期望律（Law of Total Expectation / Tower Rule）**：
$$E[Y] = E\left[E[Y \mid X]\right]$$

这是统计推断中反复使用的核心工具——把复杂期望分解为先条件化再平均。

## 方差

### 定义
$$\operatorname{Var}(X) = E\left[(X - E[X])^2\right] = E[X^2] - (E[X])^2$$

### 核心性质

| 性质 | 公式 |
|------|------|
| 缩放 | $\operatorname{Var}(aX) = a^2\operatorname{Var}(X)$ |
| 平移不变 | $\operatorname{Var}(X + c) = \operatorname{Var}(X)$ |
| 独立时求和 | $\operatorname{Var}(X+Y) = \operatorname{Var}(X) + \operatorname{Var}(Y)$（若独立） |

### 条件方差分解
$$\operatorname{Var}(Y) = \underbrace{E[\operatorname{Var}(Y \mid X)]}_{\text{组内方差期望}} + \underbrace{\operatorname{Var}(E[Y \mid X])}_{\text{组间方差}}$$

> 直觉：总变异 = 组内噪声 + 组间信号。这是 ANOVA、$R^2$、Bias-Variance 分解的共同根源。

## 协方差与相关

### 协方差
$$\operatorname{Cov}(X,Y) = E[(X - E[X])(Y - E[Y])] = E[XY] - E[X]E[Y]$$

### 相关系数
$$\rho_{XY} = \frac{\operatorname{Cov}(X,Y)}{\sqrt{\operatorname{Var}(X)\operatorname{Var}(Y)}} \in [-1, 1]$$

### 和的一般方差
$$\operatorname{Var}(X+Y) = \operatorname{Var}(X) + \operatorname{Var}(Y) + 2\operatorname{Cov}(X,Y)$$

### 协方差矩阵（多元）
对随机向量 $\mathbf{X} = (X_1, \dots, X_p)^T$：
$$\Sigma = E\left[(\mathbf{X} - \boldsymbol{\mu})(\mathbf{X} - \boldsymbol{\mu})^T\right]$$

$\Sigma_{ij} = \operatorname{Cov}(X_i, X_j)$，对角线上是方差。协方差矩阵是**半正定对称矩阵**。

## 关键不等式

### Markov 不等式
$$P(|X| \geq t) \leq \frac{E[|X|]}{t},\quad t>0$$

### Chebyshev 不等式
$$P(|X - \mu| \geq t) \leq \frac{\sigma^2}{t^2}$$

### Cauchy-Schwarz 不等式
$$|E[XY]| \leq \sqrt{E[X^2]E[Y^2]}$$

由此推出 $|\operatorname{Cov}(X,Y)| \leq \sqrt{\operatorname{Var}(X)\operatorname{Var}(Y)}$，即 $|\rho| \leq 1$。

## 与统计推断的关系

- **MLE**：Fisher 信息 = 得分函数的方差；渐近方差 = 逆 Fisher 信息
- **假设检验**：检验统计量的方差决定检验功效
- **因果推断**：$\operatorname{Var}(E[Y \mid X])$ 衡量 $X$ 能解释多少变异
- **Bias-Variance Tradeoff**：预测误差 = (Bias)² + Variance + 不可约噪声
