# 贝叶斯统计

## 核心思想

与频率学派不同，贝叶斯统计把 **参数 $\theta$ 视为随机变量**，用概率分布来表达不确定性。

$$P(\theta \mid \text{数据}) = \frac{P(\text{数据} \mid \theta) \cdot P(\theta)}{P(\text{数据})}$$

即：
$$\underbrace{\pi(\theta \mid X)}_{\text{后验}} = \frac{\overbrace{f(X \mid \theta)}^{\text{似然}} \cdot \overbrace{\pi(\theta)}^{\text{先验}}}{\underbrace{\int f(X \mid \theta)\pi(\theta)\,d\theta}_{\text{边缘似然（归一化常数）}}}$$

核心公式：**后验 ∝ 似然 × 先验**。

## 三个要素

### 1. 先验分布 $\pi(\theta)$
反映在观察数据前对 $\theta$ 的信念。

| 类型 | 含义 | 示例 |
|------|------|------|
| **无信息先验** | 最小化先验影响 | $\pi(\theta) \propto 1$（均匀）、Jeffreys 先验 |
| **共轭先验** | 后验与先验同族 | Beta-Binomial、Normal-Normal、Gamma-Poisson |
| **信息先验** | 编码领域知识 | 来自历史数据或专家判断 |
| **分层先验** | 超参数也有先验 | 多层贝叶斯模型 |

### 2. 似然函数 $f(X \mid \theta)$
与频率学派相同——数据生成机制。

### 3. 后验分布 $\pi(\theta \mid X)$
观察数据后对 $\theta$ 的更新信念。所有推断基于后验。

## 共轭先验速查表

| 似然 | 先验 | 后验 |
|------|------|------|
| $Bin(n,\theta)$ | $Beta(a,b)$ | $Beta(a + x,\ b + n - x)$ |
| $Pois(\lambda)$ | $Gamma(\alpha,\beta)$ | $Gamma(\alpha + \sum x_i,\ \beta + n)$ |
| $N(\mu, \sigma^2),\ \sigma^2$ 已知 | $N(\mu_0, \tau^2)$ | $N\left(\frac{\frac{\mu_0}{\tau^2} + \frac{n\bar{x}}{\sigma^2}}{\frac{1}{\tau^2} + \frac{n}{\sigma^2}},\ \frac{1}{\frac{1}{\tau^2} + \frac{n}{\sigma^2}}\right)$ |

> 共轭性让计算可以直接解析得到后验参数，无需 MCMC。

## 推断方式

### 点估计
- **后验均值**：$\hat{\theta} = E[\theta \mid X] = \int \theta \,\pi(\theta \mid X)\,d\theta$（最小化后验均方误差）
- **后验众数（MAP）**：$\hat{\theta} = \arg\max_\theta \pi(\theta \mid X)$（等价于带正则化的 MLE）
- **后验中位数**：最小化 $L^1$ 损失

### 区间估计：可信区间
$100(1-\alpha)\%$ **可信区间** $C$ 满足：
$$P(\theta \in C \mid X) = 1-\alpha$$

与频率学派的置信区间不同——可信区间直接说"$\theta$ 在 $C$ 内的概率是 95%"，这正是人们直觉想要的。

### 假设检验：贝叶斯因子
$$BF_{10} = \frac{P(X \mid H_1)}{P(X \mid H_0)} = \frac{\text{边缘似然 under }H_1}{\text{边缘似然 under }H_0}$$

| $BF_{10}$ | 解释 |
|-----------|------|
| 1–3 | 微弱证据 |
| 3–10 | 中等证据 |
| 10–100 | 强证据 |
| >100 | 决定性证据 |

> 贝叶斯因子直接比较两个假设的证据强度，而 p 值只衡量 $H_0$ 下数据的极端程度。贝叶斯因子不需要多重检验校正。

## 计算：MCMC

当后验无法解析求解时，用马尔可夫链蒙特卡洛（MCMC）抽样近似：

- **Metropolis-Hastings**：通过接受/拒绝从目标分布采样
- **Gibbs 采样**：轮流从各参数的条件后验采样（Metropolis-Hastings 特例）
- **Hamiltonian Monte Carlo (HMC)**：利用梯度信息高效探索后验（Stan 默认算法）
- **NUTS**：自适应调整步数的 HMC（No-U-Turn Sampler）

## 关键直觉

### 1. 先验的影响随样本量递减
$$\text{后验方差} \approx \frac{1}{\frac{1}{\text{先验方差}} + \frac{n}{\text{似然方差}}} \to 0 \text{ 当 } n \to \infty$$

大样本下，先验的影响被数据淹没 → 贝叶斯与频率学派趋同（Bernstein-von Mises 定理）。

### 2. 贝叶斯是天然的正则化
MAP 估计 $\propto$ 似然 × 先验 → 先验充当惩罚项。例如：
- Laplace 先验 → L1 正则化（Lasso）
- 正态先验 → L2 正则化（Ridge）

### 3. 不确定性量化是内置的
频率学派需要 Bootstrap 或 Delta 方法来获得不确定性；贝叶斯直接从后验获得完整分布。

## 与频率学派的系统对比

| 维度 | 频率学派 | 贝叶斯学派 |
|------|---------|-----------|
| $\theta$ 的本质 | 固定未知常数 | 随机变量 |
| 概率的含义 | 长期频率 | 信念/不确定性的程度 |
| 推断工具 | 置信区间、p 值 | 可信区间、后验概率、贝叶斯因子 |
| 区间解释 | "95% 的区间包含 $\theta$" | "$\theta$ 在区间内的概率 95%" |
| 先验信息 | 不纳入（或隐式） | 显式建模 |
| 计算 | 通常解析或优化 | 解析（共轭）或 MCMC |

> 不是非此即彼——许多现代方法（如 TMLE 中的贝叶斯成分、变分推断）融合了两者。
