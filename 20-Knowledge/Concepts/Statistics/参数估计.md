# 参数估计

## 问题设定

有数据 $X_1, \dots, X_n \sim p(x \mid \theta)$，$\theta \in \Theta \subseteq \mathbb{R}^d$ 未知。目标：用数据构造估计量 $\hat{\theta}_n = g(X_1,\dots,X_n)$ 来推断 $\theta$。

## 估计量评价标准

### 偏差（Bias）
$$\operatorname{Bias}(\hat{\theta}) = E[\hat{\theta}] - \theta$$

$\operatorname{Bias}=0$ → **无偏**。偏差衡量估计量的系统误差。

### 方差
$$\operatorname{Var}(\hat{\theta}) = E\left[(\hat{\theta} - E[\hat{\theta}])^2\right]$$

衡量估计量在不同样本间的波动。

### 均方误差（MSE）
$$\operatorname{MSE}(\hat{\theta}) = E\left[(\hat{\theta} - \theta)^2\right] = \underbrace{\operatorname{Bias}^2(\hat{\theta})}_{\text{偏差平方}} + \underbrace{\operatorname{Var}(\hat{\theta})}_{\text{方差}}$$

> **核心洞察**：准确 = 瞄准正确（低偏差）+ 稳定（低方差）。偏差-方差权衡是统计学习的核心。

### 一致性
$$\hat{\theta}_n \xrightarrow{P} \theta \quad \text{（当 } n \to \infty \text{）}$$

即 $\forall \varepsilon>0, \lim_{n\to\infty} P(|\hat{\theta}_n - \theta|>\varepsilon) = 0$。

> 充分条件：$\operatorname{MSE} \to 0$（即偏差和方差都趋于 0）

## 主要方法

### 1. 矩估计（Method of Moments）
用样本矩匹配总体矩：
$$E[X^k] = \frac{1}{n}\sum_{i=1}^n X_i^k$$

简单直观，但效率通常不如 MLE。

### 2. 最大似然估计（MLE）
$$\hat{\theta}_{\text{MLE}} = \arg\max_\theta \prod_{i=1}^n p(X_i \mid \theta)$$

等价最大化对数似然：$\ell(\theta) = \sum \log p(X_i \mid \theta)$。

详见 [[最大似然估计]]。

### 3. 贝叶斯估计
把 $\theta$ 视为随机变量，用后验分布做推断。详见 [[贝叶斯统计]]。

## MLE 的优良性质（大样本）

在正则条件下：

| 性质 | 含义 |
|------|------|
| **一致性** | $\hat{\theta}_n \xrightarrow{P} \theta$ |
| **渐近正态** | $\sqrt{n}(\hat{\theta}_n - \theta) \xrightarrow{d} N(0, I(\theta)^{-1})$ |
| **渐近有效** | 渐近方差达到 Cramér-Rao 下界（最小可能方差） |
| **等变性** | 若 $\phi = g(\theta)$，则 $\hat{\phi}_{\text{MLE}} = g(\hat{\theta}_{\text{MLE}})$ |

其中 **Fisher 信息**：
$$I(\theta) = -E\left[\frac{\partial^2}{\partial\theta^2}\log p(X \mid \theta)\right] = E\left[\left(\frac{\partial}{\partial\theta}\log p(X \mid \theta)\right)^2\right]$$

### Cramér-Rao 下界
对任意无偏估计量 $\hat{\theta}$：
$$\operatorname{Var}(\hat{\theta}) \geq \frac{1}{n I(\theta)}$$

> MLE 渐近达到此下界——在"用最少数据获得最多信息"的意义下是最优的。

## 置信区间

参数 $\theta$ 的 $100(1-\alpha)\%$ 置信区间：随机区间 $[L, U]$ 满足
$$P(L \leq \theta \leq U) = 1 - \alpha$$

### 基于 MLE 的 Wald 区间
$$\hat{\theta} \pm z_{\alpha/2} \cdot \widehat{SE}(\hat{\theta})$$

其中 $\widehat{SE} = (n I(\hat{\theta}))^{-1/2}$。

### Bootstrap 区间
非参数重采样，不依赖渐近正态假设。适用于复杂估计量。
