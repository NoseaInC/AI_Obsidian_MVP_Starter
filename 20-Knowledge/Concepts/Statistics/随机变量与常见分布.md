# 随机变量与常见分布

## 随机变量

**随机变量** $X: \Omega \to \mathbb{R}$ 是从样本空间到实数的可测函数。

### 累积分布函数（CDF）
$$F_X(x) = P(X \leq x)$$

性质：非降、右连续、$\lim_{x\to -\infty}F(x)=0$、$\lim_{x\to +\infty}F(x)=1$

### 概率质量函数（PMF）— 离散
$$p_X(x) = P(X = x)$$

### 概率密度函数（PDF）— 连续
$$f_X(x) = \frac{d}{dx}F_X(x)$$

即 $P(a \leq X \leq b) = \int_a^b f_X(x)\,dx$

## 离散分布

| 分布 | PMF | 参数 | 直觉 |
|------|-----|------|------|
| **伯努利** | $p^x(1-p)^{1-x}$ | $p \in [0,1]$ | 一次成败 |
| **二项** $Bin(n,p)$ | $\binom{n}{x}p^x(1-p)^{n-x}$ | $n \in \mathbb{N}, p$ | $n$ 次独立伯努利 |
| **泊松** $Pois(\lambda)$ | $\frac{\lambda^x e^{-\lambda}}{x!}$ | $\lambda > 0$ | 单位时间随机事件计数 |
| **几何** | $(1-p)^{x-1}p$ | $p$ | 首次成功所需试验次数 |
| **负二项** | $\binom{x-1}{r-1}p^r(1-p)^{x-r}$ | $r,p$ | 第 $r$ 次成功所需次数 |

## 连续分布

| 分布 | PDF | 参数 | 直觉 |
|------|-----|------|------|
| **均匀** $U(a,b)$ | $\frac{1}{b-a}$ | $a<b$ | 区间内等可能 |
| **正态** $N(\mu,\sigma^2)$ | $\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu,\sigma^2$ | CLT 的极限 |
| **指数** $Exp(\lambda)$ | $\lambda e^{-\lambda x}$ | $\lambda>0$ | 无记忆等待时间 |
| **Gamma** $\Gamma(\alpha,\beta)$ | $\frac{\beta^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\beta x}$ | $\alpha,\beta$ | $n$ 个指数之和 |
| **Beta** $Beta(a,b)$ | $\frac{x^{a-1}(1-x)^{b-1}}{B(a,b)}$ | $a,b>0$ | $[0,1]$ 上的灵活分布 |
| **卡方** $\chi^2_k$ | $Gamma(k/2, 1/2)$ 特例 | $k$ df | $k$ 个独立标准正态平方和 |
| **t 分布** $t_\nu$ | — | $\nu$ df | 标准化正态/卡方根之比 |
| **F 分布** $F_{d_1,d_2}$ | — | $d_1,d_2$ df | 两个卡方（各自除以 df）之比 |

## 核心关系图

```
正态 → 独立平方和 → 卡方
卡方 / df 之比 → F 分布
标准正态 / sqrt(卡方/df) → t 分布
中心极限定理：任意 i.i.d. → 样本均值 ~ N(μ, σ²/n)
```

## 指数族

许多常用分布（正态、伯努利、泊松、Gamma）都可写为指数族形式：
$$f(x \mid \theta) = h(x) \exp\left(\eta(\theta)^T T(x) - A(\theta)\right)$$

> 指数族是 MLE 优良性质（存在充分统计量、似然函数为凸）的充分条件。
