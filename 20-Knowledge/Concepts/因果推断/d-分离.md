# d-分离

## 严谨定义

在有向无环图（DAG）$\mathcal{G}$ 中，给定节点集合 $Z$，一条路径 $p$ 被 **d-分离**（d-separated / blocked），当且仅当以下任一条件成立：

1. $p$ 包含链 $A \to B \to C$ 或分叉 $A \leftarrow B \to C$，且中间节点 $B \in Z$（条件化阻塞了信息流）；
2. $p$ 包含对撞结构 $A \to B \leftarrow C$，且 $B \notin Z$ 且 $B$ 的任意后代也 $\notin Z$（对撞节点本身阻塞路径，但条件化对撞节点反而**打开**路径）。

若 $X$ 到 $Y$ 的所有路径都被 $Z$ d-分离，则称 $X$ 和 $Y$ 在给定 $Z$ 下 **d-分离**，记为 $(X \perp\!\!\!\perp_\mathcal{G} Y \mid Z)$。

## 适用条件与假设

- 图 $\mathcal{G}$ 是 DAG；
- 马尔可夫假设成立：每个节点的条件分布仅依赖于其父节点；
- Faithfulness（忠实性）假设下，d-分离与条件独立等价。

## 直觉

d-分离是图论对概率条件独立的编码。三种基本结构对应三种不同的信息流：

```
链 A→B→C：     A 和 C 通过 B 关联 → 条件化 B 后阻断
分叉 A←B→C：    A 和 C 共享原因 B → 条件化 B 后阻断
对撞 A→B←C：    A 和 C 独立 → 条件化 B 后反而关联！
```

**对撞偏倚（collider bias）**是因果推断中最反直觉的陷阱之一：条件化对撞节点会在其两个原因之间引入虚假关联。例如："能力"和"颜值"在人群中独立，但若只看"明星"（能力高或颜值高被选中 → 对撞节点），能力和颜值会呈现负相关。

## 公式或关键推导

给定 DAG $\mathcal{G}$ 和不相交节点集 $X, Y, Z$：

$$X \perp\!\!\!\perp_\mathcal{G} Y \mid Z \iff \text{$X$ 到 $Y$ 的所有路径被 $Z$ d-分离}$$

在马尔可夫性和忠实性下：

$$X \perp\!\!\!\perp_\mathcal{G} Y \mid Z \iff X \perp\!\!\!\perp_P Y \mid Z$$

即图的 d-分离 ⇔ 概率的条件独立。

## 易混淆概念

- **d-分离 vs 条件独立**：d-分离是图的属性，条件独立是分布 $P$ 的属性。马尔可夫性保证 d-分离 ⇒ 条件独立；忠实性保证反过来也成立。
- **d-分离 vs 后门准则**：后门准则是 d-分离在因果效应识别中的具体应用（判断哪些变量需要调整以阻断所有后门路径）。
- **对撞偏倚 vs 混杂偏倚**：混杂是因共同原因导致的虚假关联（需条件化阻断）；对撞偏倚是因条件化对撞节点引入的虚假关联（需避免条件化）。

## 具体例子

考虑因果图：$吸烟 \to 黄手指$，$吸烟 \to 肺癌$，$基因 \to 吸烟$，$基因 \to 肺癌$。

- **后门路径**：$吸烟 \leftarrow 基因 \to 肺癌$。这是一条分叉路径——不条件化基因时，吸烟与肺癌除了因果路径外还通过基因关联。条件化基因（$Z=\{基因\}$）后，该路径被 d-分离。
- **对撞例子**：$吸烟 \to 肺癌 \leftarrow 空气污染$。吸烟和空气污染在对撞节点"肺癌"处汇合，若条件化肺癌（如只看肺癌患者），吸烟和空气污染之间会出现虚假关联。

## 常见错误

1. 混淆"条件化阻断路径"和"条件化打开路径"——对撞节点是反直觉的；
2. 认为给定越多协变量越好——条件化对撞节点或其后代会引入偏倚（M-bias 是典型陷阱）；
3. 仅凭直觉判断独立性而不做系统的路径分析。

## 复习题

1. 链、分叉、对撞三种基本结构中，哪些在条件化中间节点后路径被阻断？哪些反而被打开？
2. 如果一条路径同时包含链和对撞结构，给定中间某节点集 $Z$ 后路径是否被 d-分离？
3. 为什么在观测研究中"控制所有可观测变量"可能是危险的？
