## 第一层：Transformer 基础（2017）

**核心论文**：*Attention Is All You Need*

### 关键组件

- **Encoder-Decoder 结构**：Encoder 编码输入序列，Decoder 自回归生成输出
- **Self-Attention**：通过 Query / Key / Value 三个投影矩阵计算序列内各位置的关联权重
  - $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$
- **Multi-Head Attention**：多组独立的 Q/K/V 投影，并行捕捉不同子空间的语义关系
- **Positional Encoding**：正弦/余弦编码，注入序列位置信息
- **Feed-Forward Networks**：每个位置独立应用的两层 MLP
- **Layer Normalization + 残差连接**：稳定深层训练

### 最大贡献

**并行化训练** — 相比 RNN/LSTM 的逐步串行，Transformer 可同时处理整个序列，训练速度大幅提升。

## 第二层：三条演化路线

| 路线 | 代表模型 | 注意力方式 | 适用场景 |
|---|---|---|---|
| **Encoder-Only** | BERT, RoBERTa | 双向（能看到左右上下文） | 分类、NER、QA 等理解任务 |
| **Decoder-Only** | GPT-2/3/4, LLaMA, DeepSeek, Qwen | 单向 Masked（只看左侧） | 文本生成、对话、代码生成 |
| **Encoder-Decoder** | T5, BART | 编码器双向 + 解码器单向 | 翻译、摘要等 seq2seq 任务 |

> 当前主流 LLM 几乎全部采用 **Decoder-Only** 路线（GPT 系列、LLaMA、DeepSeek、Mistral、Qwen 等）。

## 第三层：关键架构创新（2020–2025）

### 位置编码

- **RoPE（旋转位置编码）**：LLaMA 系列引入。通过旋转变换将位置信息融入 Q/K 向量，支持更好的长度外推和相对位置建模。
- **ALiBi**：用线性偏置替代显式位置编码，简单高效。

### 注意力机制变体

- **MQA（Multi-Query Attention）**：所有 head 共享同一个 K/V 矩阵，大幅减少 KV Cache。PaLM 使用。
- **GQA（Grouped-Query Attention）**：MQA 与 MHA 的折中——将 head 分组，组内共享 K/V。LLaMA 2/3 使用。
- **FlashAttention**：IO-aware 实现，利用 GPU 显存层级（SRAM/HBM），将注意力计算的内存复杂度从 $O(n^2)$ 降到 $O(n)$。FlashAttention-2/3 持续优化。

### 归一化与激活

- **Pre-Norm / RMSNorm**：将 LayerNorm 移到子层之前（Pre-Norm），稳定训练；RMSNorm 去掉均值和偏置，更快。
- **SwiGLU / GeGLU**：用门控线性单元替代 ReLU，LLaMA 等模型验证效果优于传统 FFN 激活。

### 稀疏架构

- **MoE（Mixture of Experts）**：将 FFN 层替换为多个「专家」子网络，每个 token 只路由到 top-k 个专家。
  - 代表：Mixtral 8×7B、DeepSeek-V2/V3
  - 优势：总参数量巨大但每次推理只激活部分参数，训练和推理更高效

## 第四层：训练与推理系统

### 分布式训练并行策略

| 策略 | 原理 | 代表框架 |
|---|---|---|
| **Data Parallelism** | 数据分片到多卡，各自前向+反向，梯度同步 | PyTorch DDP |
| **FSDP / ZeRO** | 优化器状态、梯度、参数分片；ZeRO-1/2/3 逐步深入 | DeepSpeed, PyTorch FSDP |
| **Tensor Parallelism** | 单层内的矩阵运算切分到多卡 | Megatron-LM |
| **Pipeline Parallelism** | 不同层分配到不同设备，微批次流水线执行 | GPipe, PipeDream |
| **3D 混合并行** | 三者组合：DP + TP + PP | 超大模型训练标配 |

### 推理优化

- **KV Cache**：缓存已计算的 Key/Value，避免重复计算
- **Continuous Batching**：动态批处理，请求完成后立即替换为新请求（vLLM）
- **Speculative Decoding**：小模型快速生成草稿，大模型验证，加速生成
- **量化**：降低权重精度以减少显存和加速推理
  - GPTQ / AWQ（训练后量化）
  - GGUF（CPU 推理常用）
  - FP8 / INT8 / INT4
