# 非参数估计方程（有效影响曲线）

## 严谨定义
在非参数模型中，一个渐近有效的估计量必须满足 ϕ(y, t, x; Q, g, ψ) = 0 的样本均值，其中 ϕ 为感兴趣参数 ψ 的有效影响曲线。对 ATE，ϕ = Q(1, x) - Q(0, x) + [t/g - (1-t)/(1-g)] (y - Q(t, x)) - ψ。

## 适用条件与假设
Q 和 g 为真实函数的相合估计量。

## 直觉
该方程概括了所有正则渐近线性估计量的影响函数，满足它可以同时获得双稳健性和局部有效性，即只要 Q 或 g 之一正确，估计量一致，且在此类中方差最小。

## 公式或关键推导
ϕ(y, t, x; Q, g, ψ) = Q(1, x) - Q(0, x) + ( t/g(x) - (1-t)/(1-g(x)) ) ( y - Q(t, x) ) - ψ

## 易混淆概念
样本量有限时，满足该方程的估计量未必表现好，因为分母 g 接近 0 或 1 时方差极大；但该方程为构建估计量提供了渐近保证。

## 具体例子
A-IPTW 估计量通过解 1/n Σ ϕ = 0 求得 ˆψ；TMLE 通过对 Q 的扰动使简单均值差满足此方程。

## 常见错误
混淆估计方程与估计量本身；忽略估计方程只定义了渐近性质而非小样本性质。
