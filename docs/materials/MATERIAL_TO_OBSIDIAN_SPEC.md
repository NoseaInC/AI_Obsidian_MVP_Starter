# Material to Obsidian Spec

Updated: 2026-07-14

## Unified intake

PDF, textbook, AI conversation, text/Markdown, explicit local path/folder and public URL enter through the assistant. Every attachment first creates a traceable Material Artifact.

Raw bodies remain in `90-Local-Only`; local external files are referenced rather than copied unless the user explicitly uploads them. SQLite stores hashes, type, status and private references, never full text.

## Outcomes

- PDF/textbook: immutable Prepared Bundle → inspect → explicitly gated apply.
- Public URL: Material + Research Bundle; explicit save creates a Change Set.
- Text/conversation: local archive + structured proposal/learning result.
- Folder/path: explicit selection, threshold confirmation and manifest.

Formal knowledge is written only through Change Set, verification and transaction. reviewed/core conflicts create update suggestions. Sources and important claims retain page or source evidence.
